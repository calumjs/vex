`vex` is a Rust binary that searches code and GitHub issues by semantic meaning rather than exact tokens. No index, no background process, no setup phase — run it against any directory and get ranked results in under a second.

```
vex "error handling with retries" src/
```

## The problem

Keyword search assumes you know the vocabulary the code uses. On a working codebase, you often don't. `rg "retry"` won't surface `fetch_with_retry`, `handle_failure`, or `CircuitBreakerPolicy`. A search for "authentication" misses the PR discussion titled "session management overhaul." The context exists; the words differ.

This gap widens as engineering context moves outside the code. Decisions land in GitHub issues, PR discussions, and architecture docs. Three months later, that reasoning is findable only by whoever remembered where to look.

The problem compounds for AI-assisted workflows. If an agent can't find the context, it can't use it — decisions get repeated, bugs get reintroduced, tribal knowledge stays tribal.

## How it works

Each query runs a short pipeline: walk files, score by keyword overlap, chunk the top candidates using tree-sitter (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#) or paragraph splitting for prose and other formats, BM25 pre-filter to the top ~50 chunks, embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized via ONNX Runtime), rank by cosine similarity.

Steps 2–4 eliminate more than 99% of chunks before the neural model runs. That's why query-time embedding is viable without a pre-built index: a 19k-file monorepo cold-searches in 729ms on a Snapdragon X Elite.

GitHub issues and PRs can be materialized locally with `vex sync github`. Subsequent syncs are incremental via a watermark in `.meta/sync-state.json`. After sync, every query returns code and discussions side by side, ranked together.

## Getting started

Requires [Rust](https://rustup.rs/):

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads automatically on first run. Add `~/.cargo/bin` to `PATH` if not already there — see the [README](https://github.com/calumjs/vex#install) for platform-specific instructions.

vex ships a `/vex` Claude Code skill (`skills/vex/SKILL.md`) that teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls from an agent. Install it globally or clone the repo — it's available automatically in any Claude Code session within the project.
