`vex` is a Rust CLI for semantic search across code, documentation, and GitHub issues. No index to build, no server to run, one binary. Point it at a directory, ask a question in natural English, and get ranked results in under a second.

```
vex "database connection pooling" src/
```

## The problem it solves

Keyword search assumes you already know the vocabulary the code uses. A search for `retry` misses `fetch_with_retry`. A search for `authentication` misses the PR discussion titled "session management redesign." The context exists; the words diverge; `grep` and `ripgrep` can't bridge the gap.

This compounds as codebases grow and AI tools like Claude Code navigate them. If context can't be found, it can't be used — decisions get repeated, bugs get reintroduced, and institutional knowledge stays locked in the heads of the people who were there.

## How it works

Walk files in parallel, score by keyword overlap, chunk with tree-sitter at function and class boundaries, narrow to the top candidates via BM25 pre-filter, embed query and candidates with [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) (384-dim, INT8 quantized via ONNX Runtime on CPU), rank by cosine similarity. Steps 2–4 eliminate >99% of chunks before the neural model runs — indexing at query time is fast enough.

`vex sync github` pulls issues and pull requests down as local Markdown files. After that, every search includes them alongside source code. Search for "why did we change the auth flow" and get the PR discussion, the architecture doc, and the implementation, ranked together by relevance.

`vex` ships with a `/vex` Claude Code skill (`skills/vex/SKILL.md`) that instructs Claude to expand queries with `--literal` synonym hints, run follow-up queries from different angles, and trace code flow from results. A single `vex` invocation replaces 10–15 grep/glob/read calls, saving tokens and context window.

Benchmarked on Snapdragon X Elite (12-core Oryon, ARM64): a 585-file codebase searches in 468ms; a 19,366-file monorepo in 729ms. Cold search, no cache.

Supported tree-sitter languages: Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#. Other file types fall back to paragraph and sliding-window chunking — `vex` works on any text.

## Getting started

Requires [Rust](https://rustup.rs/).

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup, `vex sync github` credentials, and the full option reference.
