`vex` is a Rust CLI (`cargo install --git https://github.com/calumjs/vex`) that runs semantic search over a codebase at query time — no index, no server, no cache. Point it at a directory or a synced GitHub issue store and it returns ranked matches by meaning, not token.

## The problem

Keyword search assumes you know the vocabulary the code uses. You don't, when the concept you're looking for was named by someone else six months ago. `rg "retry"` misses `fetch_with_retry`, `handle_failure`, and `CircuitBreakerPolicy`. `rg "authentication"` misses the PR discussion about session management. The context exists; the words diverge; grep can't bridge the gap.

This compounds in AI-assisted workflows. If Claude Code can't locate the relevant context, it reasons without it — decisions get repeated, bugs get reintroduced, and tribal knowledge stays tribal.

## How it works

Each query runs five stages:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score by keyword overlap — drop files with zero overlap.
3. Chunk top files at function/class boundaries (tree-sitter) or paragraphs (prose/Markdown). Supported languages: Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#.
4. BM25 pre-filter narrows to ~50 candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8, ONNX Runtime) and rank by cosine similarity.

Steps 2–4 eliminate >99% of chunks before the model runs. On a 19,366-file monorepo, cold search returns in 729ms on a Snapdragon X Elite. On a 585-file .NET app, 468ms.

## GitHub sync

`vex sync github` pulls issues and PRs down as local Markdown under `~/.local/share/vex/sources/github/`. After that, every query includes them alongside code — search for "why did we change the auth flow" and get the PR discussion, the ADR, and the implementation, ranked together.

Credentials resolve via `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN`. Subsequent syncs are incremental; watermark in `.meta/sync-state.json`.

## Claude Code skill

The `/vex` slash command (`.claude/skills/vex/SKILL.md`) teaches Claude how to use `vex` effectively: synonym expansion with `--literal`, follow-up queries from orthogonal angles, and code-flow tracing from the top result. One `vex` call typically replaces ten-to-fifteen `grep`/`glob`/`read` sequences.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup on Windows and Linux/macOS, and for optional Claude Code skill installation.
