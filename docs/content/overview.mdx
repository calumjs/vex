`vex` is a Rust CLI that searches code and engineering context by meaning, not by keyword. No index, no server, no daemon. A single binary: point it at a directory, ask a question in plain English, and get ranked results in under a second.

## The problem

Keyword search assumes you know the vocabulary the code uses. On a non-trivial codebase, you often don't. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR discussion about session management. The code and context exist; the words differ; grep can't bridge the gap.

The problem compounds across GitHub issues and PRs. A bug might be described in an issue as "connection reuse" and in the code as `PooledClient`. A design decision might live in a PR review that nobody documented. `vex sync github` pulls that context down as local Markdown, so a single search returns the implementation and the discussion that motivated it — ranked together by relevance.

This matters especially in AI-assisted workflows. If `vex` can't surface the right context, Claude Code can't use it. The `/vex` skill (`skills/vex/SKILL.md`) teaches Claude to use `vex` for synonym expansion, follow-up queries, and code flow tracing — replacing 10–15 `grep`/`glob`/`read` calls per investigation, saving tokens and context window.

## How it works

```bash
# Search the current directory
vex "error handling with retries" src/

# Bridge vocabulary gaps explicitly
vex "race condition prevention" --literal lock --literal mutex

# Include synced GitHub issues and PRs
vex "resilience strategy" src/ ~/.local/share/vex/sources/github/owner/repo/
```

The pipeline: walk files (`.gitignore`-aware), score by keyword overlap, chunk with tree-sitter at function/class boundaries (Rust, Python, JS, TS, Go, C, C++, Java, C#; prose falls back to paragraph splitting), BM25 pre-filter, embed query + top candidates with all-MiniLM-L6-v2 (INT8 ONNX, multi-core), rank by cosine similarity.

Steps 2–4 eliminate >99% of chunks before the neural model runs. On a 19,000-file monorepo: 729ms cold. No pre-indexing required.

## Getting started

Requires Rust:

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. [See the README](https://github.com/calumjs/vex) for PATH setup, GitHub sync auth, and the full options reference.
