`vex` is a command-line semantic search tool written in Rust. Single binary, no index, no background process. Embeds a query and candidate code chunks at query time using `all-MiniLM-L6-v2` (384-dim, INT8-quantized) via ONNX Runtime, then ranks by cosine similarity.

```
vex "error handling with retries" src/
```

## The problem

Keyword search fails across the vocabulary gap. `rg "retry"` doesn't find `fetch_with_retry` or the issue titled "Resilience strategy for upstream timeouts." As codebases grow and engineering context spreads across code, GitHub issues, PR discussions, and design docs, unfindable context leads to repeated decisions and reintroduced bugs. AI agents navigating a codebase with only keyword search make the same omissions at higher speed.

## The pipeline

1. Walk files (`.gitignore`- and `.vexignore`-aware, parallel)
2. Score by keyword overlap; discard files with zero matches
3. Chunk top files — tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph/sliding-window for prose
4. BM25 pre-filter to ~50 candidates
5. Neural embed query + candidates (ONNX, INT8, up to 12 threads)
6. Cosine similarity → ranked top-k

Steps 2–4 eliminate >99% of chunks before the neural model runs. Cold latency: 468ms on a 585-file .NET app, 729ms on a 19k-file monorepo (Snapdragon X Elite, ARM64). No pre-indexing. No cache.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/issues/` and `.../prs/`. Sync is incremental via a watermark in `.meta/sync-state.json`; `--force` resets it. After sync, every `vex` query automatically scores synced content alongside code — implementation and discussion in one ranked list.

Credential resolution: `gh auth token` → `GITHUB_TOKEN` → `GH_TOKEN`. Only needed at sync time; search runs fully locally over materialized Markdown.

## Install

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads automatically on first run. For PATH setup on Windows and Linux/macOS, see the [README](https://github.com/calumjs/vex#install).

The `/vex` Claude Code skill (`skills/vex/SKILL.md`) teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls.
