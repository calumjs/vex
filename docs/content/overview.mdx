`vex` is a CLI tool written in Rust that searches code, docs, and GitHub issues by meaning rather than by keyword. Single binary, no index, no server, no background process. Cold search on a 19k-file monorepo completes in 729ms on a Snapdragon X Elite.

## The problem

Keyword search assumes you know the vocabulary the code uses. On any non-trivial codebase, you often don't. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR discussion about session management. The context exists; the words differ; grep can't bridge the gap.

This becomes more acute as codebases grow and AI tools like Claude Code navigate them. If the context can't be found, it can't be used — decisions get repeated, bugs get reintroduced, and tribal knowledge stays tribal.

## How it works

Each query runs a six-step pipeline:

1. **Walk** files in parallel, respecting `.gitignore` and `.vexignore`.
2. **Score** files by keyword overlap with the query; drop files with no overlap.
3. **Chunk** the top 200 files — tree-sitter (function/class boundaries) for code, paragraph splitting for prose.
4. **BM25 pre-filter** narrows to ~50 candidates lexically.
5. **Embed** query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime on CPU.
6. **Rank** by cosine similarity; return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is what makes query-time embedding viable without pre-indexing.

## GitHub sync

`vex sync github` pulls issues and PRs down as local Markdown. After that, every `vex` search includes them alongside code. Search for "why did we change the auth flow" and get the PR discussion, the architecture doc, and the implementation — ranked together by relevance. Sync is incremental via a watermark in `.meta/sync-state.json`.

```bash
vex sync github                          # auto-detect repo from git remote
vex sync github calumjs/vex --state open # only open issues
```

Credentials resolve in order: `gh auth token`, `GITHUB_TOKEN`, `GH_TOKEN`. Only used during sync; search runs over materialized local Markdown.

## Install

Requires [Rust](https://rustup.rs/).

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. Add `~/.cargo/bin` to your PATH.

## Claude Code skill

The optional `/vex` slash command teaches Claude how to use vex effectively: synonym expansion, follow-up queries, flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls.

```bash
mkdir -p ~/.claude/skills/vex
cp .claude/skills/vex/SKILL.md ~/.claude/skills/vex/
```

Or clone the repo — the skill is available automatically in any Claude Code session within it.

## Supported languages

Tree-sitter chunking: Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#. Other file types fall back to paragraph/sliding-window chunking.
