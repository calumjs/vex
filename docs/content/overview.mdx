`vex` is a Rust CLI that searches code and engineering context by meaning rather than keyword. No index, no server, no background process — embed at query time, return results in under a second.

```bash
vex "error handling with retries" src/
```

## The problem

Keyword search assumes you already know the vocabulary the code uses. It rarely lines up: "retry" misses `fetch_with_retry`, "authentication" misses the PR discussion about session management, "race conditions" misses the module using `lock` and `mutex`. The context exists; `grep` can't bridge the gap.

This compounds when AI tools like Claude Code navigate the codebase. Context that can't be located can't be used — decisions get repeated, bugs get reintroduced, and tribal knowledge stays tribal.

## How it works

Each query runs a five-stage pipeline:

1. Walk files respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap — zero-overlap files are dropped immediately.
3. Chunk the top 200 files using tree-sitter for code (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#) or paragraph/sliding-window for prose.
4. BM25 pre-filter narrows to the top ~50 candidates lexically.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime; rank by cosine similarity.

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is what makes query-time embedding viable without pre-indexing — a 19k-file monorepo cold-searches in 729ms on a Snapdragon X Elite.

### GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/<owner>/<repo>/`, with YAML frontmatter. After sync, every `vex` query includes them alongside code automatically. Search "why did we change the auth flow" and get the PR discussion together with the implementation, ranked by relevance. Sync is incremental; the watermark lives in `.meta/sync-state.json`.

### Claude Code skill

`/vex` is a bundled Claude Code skill that teaches agents to use semantic search effectively — synonym expansion via `--literal`, multi-angle follow-up queries, and call-graph flow tracing. One `vex` call replaces 10–15 grep/glob/read calls in a typical agentic session.

## Getting started

Install via Cargo — the embedding model (~23 MB quantized) downloads on first run:

```bash
cargo install --git https://github.com/calumjs/vex
```

[See the README](https://github.com/calumjs/vex) for PATH setup, Claude Code skill install, and the full option reference (`-k`, `-t`, `-g`, `--literal`, `--fast`, `--device`, `--json`).
