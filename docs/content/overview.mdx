`vex` is a command-line Rust binary that runs semantic search over source code and optionally synced GitHub issues and PRs. No index, no server, no background process — queries embed at runtime against local files and return ranked results in under a second on most codebases.

## The vocabulary gap problem

Keyword search assumes you already know the terms the code uses. In practice you often don't: searching for `retry` misses `fetch_with_retry`; searching for `authentication` misses the PR discussion titled "Resilience strategy for upstream timeouts." The gap widens as codebase size increases and AI-assisted navigation becomes the norm — an agent that can only grep what it already knows gets stuck exactly where the useful context lives.

`vex` closes that gap. A query like `vex "error handling with retries" src/` ranks `fetch_with_retry` in `src/client.rs`, `handle_failure` in `src/worker.rs`, and the design doc explaining the resilience strategy — across code and prose alike, without prior indexing.

`vex sync github` materializes issues and PRs into local Markdown under `~/.local/share/vex/sources/github/owner/repo/` with YAML frontmatter. After that, every `vex` search includes them alongside your code. Subsequent syncs are incremental via a watermark in `.meta/sync-state.json`. Credentials resolve in order: `gh auth token`, `GITHUB_TOKEN`, `GH_TOKEN`.

## Pipeline

```
query → keyword-score files → tree-sitter/paragraph chunk → BM25 pre-filter → embed (all-MiniLM-L6-v2, INT8, ONNX) → cosine rank
```

Steps 2–4 drop > 99% of chunks before the neural model runs. That's what makes query-time embedding viable: a 19k-file monorepo returns in 729ms cold on a Snapdragon X Elite. Tree-sitter chunking covers Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, and C#; other file types fall back to paragraph/sliding-window splits.

The `--literal <TERM>` flag boosts files containing a specific keyword before the neural pass — useful when you know part of the vocabulary: `vex "race conditions" --literal lock --literal mutex`. Full option set: `-k` (result count), `-t` (similarity threshold), `-g` (glob filter), `-C` (context lines), `--json`, `--fast` (binary quantization), `--device npu` on supported hardware.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and sync credentials.

The repo ships a `/vex` Claude Code skill (`.claude/skills/vex/`): a slash command that teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls in an agentic context.
