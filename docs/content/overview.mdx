`vex` is a Rust command-line tool that searches code and engineering context by meaning. No index, no server, no background daemon. Pass a plain-English query; get ranked results in under a second.

```
vex "database connection pooling" src/
vex "error handling with retries" --literal backoff
```

## The problem

Keyword search assumes you know the vocabulary the code uses. You often don't. A search for `retry` misses `fetch_with_retry`. A search for `authentication` misses the PR titled "Session management rewrite" and the ADR in `docs/arch/`. The context exists; the words are different; `grep` can't bridge the gap.

The problem compounds when engineering context lives outside the code — in GitHub issues, PR discussions, design docs, and comment threads. A decision that took three PRs and six issue discussions to reach looks like a one-line change when you grep for it. `vex` treats code and GitHub content as one search corpus.

## How it works

Each query runs a six-step pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query; drop files with zero matches.
3. Chunk the top files — tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, and C#; paragraph/sliding-window for prose.
4. BM25 pre-filter narrows the pool to the top candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate more than 99% of chunks before the neural model runs. That is why no pre-indexing is needed: a 19,366-file monorepo returns cold in 729ms on a Snapdragon X Elite.

### GitHub context

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/owner/repo/` with YAML frontmatter. After a sync, every `vex` query automatically includes that content alongside code — implementation and discussion ranked together.

Sync is incremental via a watermark in `.meta/sync-state.json`. `--force` resets it. Credentials resolve via `gh auth token`, then `GITHUB_TOKEN`, then `GH_TOKEN`.

### Claude Code integration

vex ships a `/vex` slash command for [Claude Code](https://claude.com/claude-code) (`skills/vex/SKILL.md`). The skill teaches the agent synonym expansion (`--literal` hints), follow-up queries from different angles, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls from an agent.

## Getting started

Requires Rust. Install via `cargo install --git https://github.com/calumjs/vex`. The embedding model (~23 MB quantized) downloads on first run. For the Claude Code skill, copy `skills/vex/SKILL.md` to `~/.claude/skills/vex/` or clone the repo — the skill is available automatically in any Claude Code session within it. [Full install instructions](https://github.com/calumjs/vex#install).
