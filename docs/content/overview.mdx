`vex` is a Rust CLI that searches code by meaning, not keywords. No pre-built index. No background process. `vex "error handling with retries" src/` returns ranked results in under a second, cold.

## The vocabulary gap

`rg "retry"` finds the word. `vex "error handling with retries"` finds `fetch_with_retry`, `handle_failure`, `CircuitBreakerPolicy`, and the design doc explaining the resilience strategy — including the GitHub issue titled "Resilience strategy for upstream timeouts." None of them contained the word "retry."

This gap widens as context spreads beyond the codebase. `vex sync github` pulls issues and PRs down as local Markdown under `~/.local/share/vex/sources/github/owner/repo/`. After that, every `vex` search returns code and discussions ranked together. Sync is incremental; a watermark in `.meta/sync-state.json` tracks the last fetch. Credentials resolve via `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN` — only needed during sync.

## Pipeline

Each query runs six steps:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query. Zero-overlap files are dropped.
3. Chunk the top 200 files — tree-sitter at function/class boundaries for Rust, Python, JS/TS, Go, C, C++, Java, C#; paragraph splits for prose and Markdown.
4. BM25 pre-filter narrows the candidate pool to the top ~50 chunks.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Cosine similarity → rank → return top-k.

Steps 2–4 eliminate more than 99% of chunks before the ONNX model runs. That is what makes query-time embedding viable without an index: 19,366 files return in 729ms on a Snapdragon X Elite.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup.

The `/vex` Claude Code skill is optional but useful for agent workflows: it teaches Claude synonym expansion, follow-up queries, and flow tracing. One `vex` call replaces 10–15 grep/glob/read calls. Install by copying `.claude/skills/vex/SKILL.md` to `~/.claude/skills/vex/`, or clone this repo and the skill is available automatically.

Key flags: `-k N` (result count), `-g "*.cs"` (glob filter), `--literal <term>` (keyword boost for vocabulary bridging), `-t 0.3` (similarity floor), `--json` (machine output), `--fast` (binary quantization for large trees), `--device npu` (Snapdragon NPU path).
