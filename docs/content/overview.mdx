`vex` is a command-line tool written in Rust that searches code and engineering context by meaning. Single binary, no index, no server. Point it at a directory, ask a question in plain English, get ranked results in under a second.

## The problem

Keyword search assumes you know the vocabulary the code uses. Searching for `retry` misses `fetch_with_retry`; `authentication` misses a PR discussion about session handling. The gap widens as engineering context scatters across GitHub issues, ADRs, and PR threads — sources `grep` doesn't reach. AI coding agents hit the same wall: if context isn't findable, it isn't usable.

## Pipeline

vex runs a six-step pipeline at query time:

1. **Walk** — parallel file traversal, respects `.gitignore` and `.vexignore`
2. **Score** — keyword match against the query; zero-overlap files are dropped
3. **Chunk** — tree-sitter boundaries for Rust, Python, JS/TS, Go, C, C++, Java, C#; paragraph windows for prose
4. **BM25 pre-filter** — narrows to the top ~50 candidates without touching the neural model
5. **Embed** — query + candidates through `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. **Rank** — cosine similarity, return top-k

Steps 2–4 discard >99% of chunks before the neural model runs. That elimination is what makes query-time embedding viable without a pre-built index: a 19k-file monorepo returns cold in 729ms on a Snapdragon X Elite.

## GitHub sync

```bash
vex sync github              # auto-detect repo from git remote
vex sync github calumjs/vex  # explicit
```

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/owner/repo/` with YAML frontmatter. After that, every `vex` search includes them automatically. Searching `"why did we change the auth flow"` returns the PR discussion alongside the implementation. Sync is incremental via a watermark in `.meta/sync-state.json`; `--force` resets it.

## Key flags

`-k N` — result count (default 10) · `--literal <TERM>` — keyword boost before ranking · `-t 0.3` — similarity floor · `-g "*.cs"` — glob filter · `--json` — machine output · `--fast` — binary quantization (~2× faster on large trees) · `--device npu` — Snapdragon X Elite Hexagon NPU path

## Claude Code integration

`vex` ships a `/vex` skill (`skills/vex/`) for [Claude Code](https://claude.com/claude-code). The skill instructs the agent to expand queries with synonym `--literal` hints, run follow-up queries from different angles, trace code flow through top results, and combine `vex` with `grep` for a complete picture. One `vex` call typically replaces 10–15 grep/glob/read calls.

Install globally:

```bash
mkdir -p ~/.claude/skills/vex
cp .claude/skills/vex/SKILL.md ~/.claude/skills/vex/
```

Or clone this repo — the skill is automatically available within it.

## Getting started

Requires [Rust](https://rustup.rs/):

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup on Windows and Linux/macOS.
