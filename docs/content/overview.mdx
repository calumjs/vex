`vex` is a Rust CLI that searches code by meaning, not keywords. No index, no daemon — query-time embedding with `all-MiniLM-L6-v2` (ONNX, INT8 quantized), BM25 pre-filter, cosine similarity ranking. One binary, sub-second results.

## The problem

Keyword search fails when vocabulary diverges. Searching for `retry` misses `fetch_with_retry`. Searching for `authentication` misses the PR discussion about session management. The context exists in the codebase and the issue tracker; the words are different; `grep` can't bridge the gap.

`vex` bridges it:

```
vex "error handling with retries" src/
```

Results include `fetch_with_retry`, `handle_failure`, and the design doc explaining the resilience strategy — ranked by semantic similarity, not text overlap. None of those names contain "retry."

The gap matters more when AI tools navigate the codebase. If the context can't be found, it can't be used — decisions get re-litigated, bugs get reintroduced, tribal knowledge stays tribal. `vex sync github` materializes GitHub issues and PRs as local Markdown so a single query searches code and engineering discussions together.

## How it works

The pipeline:

1. Walk files in parallel, `gitignore`-aware
2. Score files by keyword overlap — zero-overlap files dropped immediately
3. Chunk top 200 files — tree-sitter at function/class boundaries for Rust, Python, JS, TS, Go, C, C++, Java, C#; paragraph splitting for prose
4. BM25 pre-filter to ~50 candidates
5. Embed query + candidates with `all-MiniLM-L6-v2` (384-dim, INT8) via ONNX Runtime
6. Rank by cosine similarity, return top-k

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is what makes query-time embedding viable without pre-indexing — a 19k-file monorepo returns in 729ms on Snapdragon X Elite, cold, no cache.

Flags: `-k N` (result count), `-g "*.rs"` (glob filter), `--literal <term>` (keyword boost for vocabulary bridging), `-t 0.3` (similarity floor), `--json`, `--fast` (binary quantization for large trees), `--device npu`.

## Getting started

Requires Rust. [See the README for install instructions](https://github.com/calumjs/vex#install). The embedding model (~23 MB quantized) downloads automatically on first run.

A `/vex` Claude Code skill lives in `.claude/skills/vex/` — copy it to `~/.claude/skills/vex/` for global availability. It teaches Claude to expand queries with `--literal` synonym hints, run follow-up queries from multiple angles, and trace code flow from results. One `vex` call replaces 10–15 grep/glob/read calls.
