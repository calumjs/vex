`vex` is a Rust command-line tool that runs semantic search at query time — no index, no server, results in under a second. Point it at a directory, ask a question in plain English, and get ranked results based on meaning rather than token overlap.

```
vex "error handling with retries" src/
```

## The vocabulary gap

Keyword search (`grep`, `ripgrep`, editor search) requires knowing the vocabulary the codebase uses. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR titled "Session management strategy." The context is there; the words are different.

This compounds when engineering reasoning is distributed across GitHub issues, PRs, and design docs. `vex sync github` materializes those as local Markdown; every subsequent search scans code and discussions together, ranked by relevance to the query. Search "why did we change the auth flow" and get the PR discussion, the architecture doc, and the implementation — together.

## Pipeline

Each query runs six steps:

1. Walk files in parallel (`.gitignore`/`.vexignore`-aware).
2. Score files by keyword overlap; drop zero-match files before chunking.
3. Chunk top 200 files — tree-sitter for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph/sliding-window for everything else.
4. BM25 pre-filter → top ~50 candidates.
5. Embed with `all-MiniLM-L6-v2` (384-dim, INT8) via ONNX Runtime. CPU default; `--device npu` on Snapdragon X Elite.
6. Rank by cosine similarity, return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. On a 19,366-file monorepo: 729ms cold. On a 585-file .NET app: 468ms cold. No pre-built index.

## Flags worth knowing

`-k N` — result count. `-g "*.cs"` — constrain by glob. `--literal <TERM>` — boost files containing a specific keyword before neural scoring, repeatable (`vex "race conditions" --literal lock --literal mutex`). `-t 0.3` — minimum similarity floor. `-C 5` — lines of context around matches. `--json` — machine-readable output. `--fast` — binary quantization, ~2× faster on very large trees at some precision cost.

## Claude Code integration

`.claude/skills/vex/` ships a `/vex` Claude Code skill. Copy it to `~/.claude/skills/vex/` for global access. The skill instructs the agent to use synonym expansion, follow-up queries, and flow tracing — one `vex` call typically replaces 10–15 grep/glob/read calls, saving tokens and context window.

## Getting started

Requires [Rust](https://rustup.rs/). [Install via `cargo install --git`](https://github.com/calumjs/vex#install). The embedding model (~23 MB quantized) downloads automatically on first run.
