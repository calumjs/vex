`vex` is a Rust CLI for semantic code search. `cargo install --git https://github.com/calumjs/vex` is the install path; the binary is self-contained — no index, no background daemon.

```
vex "error handling with retries" src/
```

Returns `fetch_with_retry`, `handle_failure`, and any design docs on resilience strategy — ranked by embedding similarity, not keyword overlap.

## The problem

`grep` and `ripgrep` require knowing the vocabulary the code uses. On any non-trivial codebase — and especially across GitHub issues, PR discussions, and ADRs — the vocabulary gap is real: "retry" and `fetch_with_backoff`, "authentication" and the session-handling PR, "why did we change the auth flow" and the issue thread that explains it.

AI-assisted workflows sharpen this. If the agent can't find the context, it can't use it — decisions get repeated, bugs get reintroduced.

## The pipeline

Each query runs six steps:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by query keyword overlap; files with zero overlap are dropped.
3. Chunk the top 200 files — tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph/sliding-window for everything else.
4. BM25 pre-filter narrows to the top ~50 candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime on CPU.
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is why indexing is unnecessary: embedding at query time is fast enough — 468ms on a 585-file .NET app, 729ms on a 19k-file monorepo, both cold, on a Snapdragon X Elite.

## GitHub sync

`vex sync github` pulls issues and PRs down as Markdown files with YAML frontmatter, stored under `~/.local/share/vex/sources/github/{owner}/{repo}/`. Subsequent syncs are incremental (watermark in `.meta/sync-state.json`). No credentials needed for search — only for sync, resolved in order from `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN`.

After syncing, searches include issues and PRs automatically alongside code results.

## Claude Code skill

`/vex` in Claude Code (`~/.claude/skills/vex/SKILL.md`) teaches the agent synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls — relevant in token-constrained sessions.
