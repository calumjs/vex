`vex` is a CLI written in Rust that runs semantic search over a codebase — or a codebase plus synced GitHub issues — without a pre-built index. Point it at a directory with a plain-English query; it embeds and ranks candidates at query time using a local neural model, returning results in under a second on codebases up to tens of thousands of files.

## The problem

Keyword search assumes you already know the vocabulary the code uses. `grep "retry"` finds the word; it misses `fetch_with_retry`, `handle_failure`, and the PR titled "Resilience strategy for upstream timeouts". On any non-trivial codebase, the vocabulary gap is real. It widens as engineering context moves into GitHub discussions, ADRs, and issue threads that were never catalogued.

For AI-assisted workflows the gap is a direct limitation: if the agent's file-finding tools can't surface the context, it can't be used. `vex "error handling with retries" src/` finds `fetch_with_retry` and `CircuitBreakerPolicy` without any of those words appearing in the query.

## How it works

```
vex "database connection pooling" src/
```

Each query runs a fixed pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query; skip files with zero overlap.
3. Chunk top candidates via tree-sitter at function/class boundaries (code) or sliding window (prose).
4. Narrow with BM25 to the top ~50 candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity, return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. That's why there's no pre-built index — the cold path is fast enough.

**GitHub sync.** `vex sync github` materializes issues and PRs as Markdown with YAML frontmatter in `~/.local/share/vex/sources/github/`. After that, a single query spans both source code and the engineering discussions that motivated it. Incremental syncs only fetch items updated since the last run.

**Tree-sitter chunking.** Supported: Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#. All other text files fall back to paragraph/sliding-window chunking.

**Claude Code skill.** `.claude/skills/vex/SKILL.md` ships a `/vex` slash command that teaches Claude how to use vex — synonym expansion via `--literal`, follow-up queries from different angles, flow tracing from a result back through call sites. One `vex` call replaces 10–15 grep/glob/read calls.

## Getting started

Requires Rust. Install from source:

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. See the [README](https://github.com/calumjs/vex) for full install instructions, path setup on Windows and Linux/macOS, and all available CLI flags.
