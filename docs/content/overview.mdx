`vex` — Vector Examine — is a command-line semantic search tool written in Rust. Single binary, no index, no background process. Point it at a source tree and ask a question in plain English; results come back ranked by meaning in under a second.

```bash
vex "error handling with retries" src/
```

## The vocabulary gap

`grep` and `ripgrep` match tokens, not intent. `rg "retry"` misses `fetch_with_retry`, `handle_failure`, and `CircuitBreakerPolicy`. The gap widens on projects where engineering context is scattered across GitHub issues, PRs, design docs, and ADRs — the decision lives somewhere; the search doesn't find it because the words don't line up.

`vex` closes the gap by embedding the query and candidate chunks with `all-MiniLM-L6-v2` (384-dim, INT8 quantized, ONNX Runtime) and ranking by cosine similarity. Steps 2–4 of the pipeline eliminate >99% of chunks before the neural model sees anything, which is what makes query-time embedding viable without pre-indexing.

## Pipeline

Each query runs in order:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap; drop files with zero matches.
3. Chunk the top 200 files — tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph/sliding-window for prose.
4. BM25 pre-filter → top ~50 candidates.
5. Embed query and candidates with ONNX Runtime on CPU (or `--device npu` on Snapdragon X Elite).
6. Rank by cosine similarity; return top-k.

Benchmarked cold on Snapdragon X Elite: 468ms on a 585-file .NET app, 729ms on a 19,366-file monorepo. No pre-indexing. No cache. Every query is cold.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/<owner>/<repo>/`. After sync, every `vex` search includes GitHub context automatically — query "why did we change the auth flow" and get the PR discussion alongside the implementation. Sync is incremental via `.meta/sync-state.json`; `--force` resets it. Credentials (via `gh auth login`, `GITHUB_TOKEN`, or `GH_TOKEN`) are only needed at sync time; search runs locally.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads on first run. The optional `/vex` [Claude Code](https://claude.com/claude-code) skill (`~/.claude/skills/vex/SKILL.md`) teaches the agent synonym expansion, follow-up queries, and flow tracing — one `vex` call typically replaces 10–15 grep/glob/read calls.
