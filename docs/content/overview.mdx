`vex` is a CLI tool that searches code, docs, and GitHub issues by meaning, not by token. Single binary, no index, no background daemon. Cold queries on a 19 k-file monorepo finish in under a second.

## The problem it solves

Keyword search assumes you already know the vocabulary the code uses. On any non-trivial codebase, you often don't. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR titled "Resilience strategy for upstream timeouts" and the session-management discussion buried in a six-month-old issue. The context exists; the words are different; grep can't bridge the gap.

This matters more as codebases grow and teams start using AI tools to navigate them. If the context can't be found, it can't be used — decisions get repeated, bugs get reintroduced, and tribal knowledge stays tribal.

## How it works

Each query runs a four-step pipeline:

1. Walk files respecting `.gitignore` and `.vexignore`, scoring by keyword overlap — files with no overlap are dropped outright.
2. Chunk the top candidates with tree-sitter (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#) or paragraph splitting for prose and Markdown.
3. BM25 pre-filter narrows to the top ~50 chunks lexically.
4. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime; rank by cosine similarity.

Steps 1–3 discard >99% of chunks before the neural model runs. That is what makes query-time embedding viable without pre-indexing.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/`. After that, every `vex` search automatically includes them alongside code. Sync is incremental via a watermark in `.meta/sync-state.json`; `--force` resets it.

```
vex "why did we change the auth flow"
```

Returns the PR discussion, the architecture doc, and the implementation — ranked together by cosine similarity.

## Claude Code skill

vex ships with a `/vex` slash command for [Claude Code](https://claude.com/claude-code). It teaches the agent synonym expansion (`--literal` hints), follow-up queries from different angles, and flow tracing. One `vex` call replaces 10–15 grep/glob/read calls, saving tokens and context window.

## Getting started

Install with Cargo:

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup, GitHub sync setup, and the full CLI reference (`-k`, `-t`, `-g`, `--literal`, `--json`, `--fast`, `--device npu`).
