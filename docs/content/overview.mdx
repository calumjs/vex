`vex` is a Rust CLI that searches code and engineering context by meaning. Single binary, no index, no daemon — embed at query time, return ranked results cold in under a second.

```
vex "error handling with retries" src/
```

## What problem it solves

Keyword search assumes you know the vocabulary the code uses. You rarely do. `rg "retry"` misses `fetch_with_retry`; `rg "authentication"` misses the PR titled "session management refactor." The context is there; the words differ; `grep` can't bridge it.

`vex` embeds the query and candidate code chunks using `all-MiniLM-L6-v2` (384-dim, INT8 quantized, ONNX Runtime) and ranks by cosine similarity. A BM25 pre-filter eliminates >99% of chunks before the model runs — that's what keeps cold search under a second on a 19k-file monorepo.

## Search scope

**Code.** Walk files in parallel, tree-sitter-chunk by function/class boundaries for supported languages (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#), paragraph-split everything else.

**GitHub issues and PRs.** `vex sync github` pulls issues and PRs into local Markdown under `~/.local/share/vex/sources/github/<owner>/<repo>/`. After sync, every `vex` invocation searches them automatically alongside code — no extra flags, same ranked list. Credentials are only needed for sync; search is fully local.

```bash
vex "why did we change the auth flow"
# → implementation in src/, PR discussion, linked issues — together, ranked
```

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. PATH setup instructions for Windows and Linux/macOS are in the [README](https://github.com/calumjs/vex#install).

**Claude Code integration.** vex ships a `/vex` skill (`skills/vex/`) that teaches agents to use semantic search effectively — synonym expansion via `--literal`, multi-angle follow-up queries, and code-flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls from an agent.

## Key options

`-k N` (result count) · `-g "*.cs"` (glob filter) · `--literal <term>` (keyword pin) · `-t 0.3` (similarity floor) · `--json` (machine output) · `--fast` (binary quantization) · `--device npu` (NPU on supported ARM64 hardware)
