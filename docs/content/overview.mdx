`vex` searches code and engineering context by meaning, not by token. A Rust CLI binary — `cargo install --git https://github.com/calumjs/vex` — that walks files, embeds your query and candidates with an INT8-quantized `all-MiniLM-L6-v2` model, and returns ranked results in under a second. No pre-indexing, no background process. Point it at a directory and ask a question.

## The problem it solves

Keyword search assumes you already know the words the code uses. A search for `retry` misses `fetch_with_backoff`. A search for `authentication` misses the PR discussion about session management. The vocabulary gap is consistent and hard to work around with grep flags.

The gap is larger on AI-assisted workflows. When Claude Code or another agent is navigating a codebase, context that can't be found can't be used — decisions get repeated, bugs get reintroduced, and the reasoning behind a design stays buried in a GitHub issue nobody links to.

`vex` also syncs GitHub issues and PRs as local Markdown, so engineering discussions are searchable alongside code. Run `vex sync github` once; every subsequent search includes them. A query like `"why did we change the auth flow"` returns the PR discussion, the ADR, and the implementation — together, ranked by relevance.

## How it works

A search invocation runs six stages:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap — files with zero overlap are dropped early.
3. Chunk top files using tree-sitter at function/class boundaries (Rust, Python, JS/TS, Go, C, C++, Java, C#), or paragraph-split for prose and Markdown.
4. BM25 pre-filter narrows to the top ~50 candidates lexically.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8, ONNX Runtime).
6. Rank by cosine similarity, return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs, which is why pre-indexing isn't needed. On a 19,000-file monorepo (35,000 chunks), cold search takes ~729ms on Snapdragon X Elite.

## Getting started

```bash
# Install
cargo install --git https://github.com/calumjs/vex

# Search current directory
vex "database connection pooling"

# Sync GitHub issues, then search code and issues together
vex sync github
vex "resilience strategy for upstream timeouts"
```

See the [README](https://github.com/calumjs/vex#install) for platform-specific PATH setup and the full options reference. The `/vex` Claude Code skill (`skills/vex/SKILL.md`) teaches Claude synonym expansion, follow-up queries, and flow tracing — copy it to `~/.claude/skills/vex/` or clone the repo.
