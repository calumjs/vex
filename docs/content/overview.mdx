`vex` is a command-line tool (Rust, single binary) that searches code and engineering context by embedding similarity rather than token matching. No index, no background daemon. Walk a directory, ask a question in plain English, get ranked results in under a second.

```
vex "error handling with retries" src/
```

## The vocabulary gap

Keyword search assumes you already know what the code calls things. On any non-trivial codebase — especially one where decisions were made months ago by people who have since moved on — that assumption fails constantly. A search for `retry` misses `fetch_with_retry`. A search for `authentication` misses the PR where the session management trade-off was made.

`vex` bridges the gap by embedding your query and the candidate chunks with `all-MiniLM-L6-v2` (384-dim, INT8 quantized, ONNX Runtime) and ranking by cosine similarity. The pipeline eliminates >99% of chunks through keyword scoring and BM25 pre-filtering before the neural model sees anything — cold search on a 19k-file monorepo completes in 729ms on a Snapdragon X Elite.

## Code and GitHub context in one search

`vex sync github` pulls issues and PRs down as local Markdown. Subsequent searches return implementation alongside the discussions that motivated it — design docs, PR threads, bug reports — ranked by relevance. Credentials are only needed during sync; search runs locally.

```bash
vex sync github                          # auto-detect repo from git remote
vex "why did we change the auth flow"   # code + issue + PR results, ranked
```

## Pipeline

1. Walk files in parallel (`.gitignore` / `.vexignore` aware)
2. Score files by keyword overlap — skip zero-overlap files
3. Chunk top files: tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph/sliding-window for prose
4. BM25 pre-filter → top ~50 candidates
5. Embed query + candidates with `all-MiniLM-L6-v2` via ONNX Runtime (CPU by default; `--device npu` on supported Qualcomm hardware)
6. Rank by cosine similarity, return top-k

## Claude Code integration

The repo ships a `/vex` Claude Code skill (`skills/vex/SKILL.md`) that teaches agents to use semantic search effectively: synonym expansion via `--literal`, follow-up queries from multiple angles, flow tracing from top results. One `vex` call typically replaces 10–15 grep/glob/Read calls, saving context window and tokens.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and the full CLI reference.
