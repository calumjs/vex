`vex` is a CLI that searches code, docs, and GitHub issues by meaning, not keywords. A single binary, no index, no server, no background daemon. Point it at a directory, ask a question in plain English, get ranked results in under a second.

## The problem

`rg "retry"` finds the word "retry". It misses `fetch_with_retry`, the issue titled "Resilience strategy for upstream timeouts", and the PR discussion where the backoff strategy was debated. The vocabulary gap between what you're looking for and how it was originally described is invisible to keyword search.

This gap matters more as codebases grow and as AI tools like Claude Code navigate them on your behalf. An agent that can't find the relevant context can't use it — decisions get repeated, bugs get reintroduced, tribal knowledge stays tribal.

## What using it looks like

```bash
vex "error handling with retries" src/
```

Returns `fetch_with_retry` at 0.42 similarity, `handle_failure` at 0.39, and any design doc covering the resilience strategy — even when none of them contain the word "retry."

Run `vex sync github` once to pull issues and PRs down as local Markdown. Every subsequent `vex` query includes them alongside code automatically. One invocation spans the codebase and the discussions that shaped it.

The pipeline is six steps: walk files respecting `.gitignore`, keyword-score to drop zero-overlap files, chunk the top candidates with tree-sitter (Rust, Python, JS/TS, Go, C, C++, Java, C#) or paragraph splitting for prose, BM25 pre-filter to the top ~50, embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime on CPU, rank by cosine similarity. Steps 2–4 eliminate >99% of chunks before the model runs — that's what makes query-time embedding viable without a pre-built index.

Benchmarked on Snapdragon X Elite: 468ms on a 585-file .NET codebase, 729ms on a 19k-file monorepo.

## Getting started

`cargo install --git https://github.com/calumjs/vex` installs the binary. The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup on Windows and Linux/macOS.

The `/vex` Claude Code skill (`.claude/skills/vex/SKILL.md`) is optional: copy it to `~/.claude/skills/vex/` to teach agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls from an agent.
