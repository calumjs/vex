`vex` is a Rust CLI binary that searches code and engineering context by meaning. No index, no server, no background process. Pass a directory and a plain-English query; get ranked results — typically under a second on large codebases.

```
vex "database connection pooling" src/
```

## The problem

Keyword search breaks when the vocabulary doesn't match. `rg "retry"` finds the word "retry" — it misses `fetch_with_retry`, `handle_failure`, and the issue titled "Resilience strategy for upstream timeouts." Code and its surrounding reasoning use different words, and `grep` can't bridge that gap.

This matters especially for AI-assisted workflows. An agent hunting for a concept will issue ten to fifteen `grep`/`glob`/`read` calls to assemble enough context for a useful answer. If the vocabulary doesn't align, it surfaces nothing.

## How it works

Each query runs a six-step pipeline:

1. **Walk** — traverse files in parallel, respecting `.gitignore` and `.vexignore`.
2. **Score** — keyword-score files; drop files with zero query overlap.
3. **Chunk** — split the top 200 files by tree-sitter boundaries (Rust, Python, JS, TS, Go, C, C++, Java, C#) or paragraph/sliding-window for prose.
4. **BM25** — lexical pre-filter narrows to ~50 candidates.
5. **Embed** — encode query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. **Rank** — cosine similarity, return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model sees anything. That is what makes query-time embedding viable without pre-indexing: 729ms cold on a 19,366-file monorepo on a Snapdragon X Elite.

## GitHub sync

`vex sync github` materializes issues and PRs as local Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/`. Each item gets YAML frontmatter (`type`, `number`, `state`, `labels`, `created`, `updated`) and inline comments. Sync is incremental via a watermark in `.meta/sync-state.json`; `--force` resets it.

After syncing, every `vex` query covers code and discussions together. `vex "why did we move to JWT"` returns the implementation alongside the PR thread that decided it, ranked by relevance.

## Getting started

Install via `cargo install --git https://github.com/calumjs/vex`. The embedding model (~23 MB, quantized) downloads automatically on first run. [See the README](https://github.com/calumjs/vex) for PATH setup and the optional `/vex` Claude Code skill — it teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces ten to fifteen grep/glob/read calls.
