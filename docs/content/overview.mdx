`vex` (Vector Examine) is a Rust CLI that runs semantic search over code files and GitHub-synced issues at query time — no index, no daemon, no setup beyond installing the binary.

## The problem

Keyword search assumes you know the vocabulary the code uses. `rg "retry"` finds the word "retry". It misses `fetch_with_retry`, `handle_failure`, and the GitHub issue titled "Resilience strategy for upstream timeouts". That vocabulary gap widens as codebases grow, as context spreads across issues and PRs, and as AI tools try to navigate the repo without prior familiarity.

```
vex "error handling with retries" src/
```

Returns `fetch_with_retry` in `src/client.rs`, `handle_failure` in `src/worker.rs`, and synced GitHub discussions about the retry policy — ranked by cosine similarity, not keyword count.

## Pipeline

Each query runs a fixed six-step pipeline:

1. Walk files (`.gitignore`- and `.vexignore`-aware), score by keyword overlap, drop zero-overlap files.
2. Chunk the top files — tree-sitter for supported languages (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#), paragraph/sliding-window for prose.
3. BM25 pre-filter narrows to ~50 candidates.
4. Embed query and candidates using `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
5. Rank by cosine similarity, return top-k.

Steps 1–3 eliminate >99% of chunks before the neural model runs. On a 19,366-file monorepo, cold results arrive in 729ms on a Snapdragon X Elite. No pre-indexing; no cache.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/owner/repo/`, with YAML frontmatter. After that, every `vex` query automatically includes them alongside code results. Search for "why did we change the auth flow" and get the PR discussion, the architecture doc, and the implementation — together, ranked by relevance.

Sync is incremental via a watermark in `.meta/sync-state.json`; `--force` re-fetches everything. Credentials resolve in order: `gh auth token`, `GITHUB_TOKEN`, `GH_TOKEN`. Only needed during sync — search runs locally over the materialized Markdown.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup on Windows and Linux/macOS.

The `/vex` Claude Code skill ships in `skills/vex/SKILL.md`. Install it globally or clone the repo — it's automatically available in any Claude Code session within it. The skill teaches the agent synonym expansion (`--literal` hints), follow-up queries, and flow tracing, typically replacing 10–15 grep/glob/read calls with one `vex` invocation.
