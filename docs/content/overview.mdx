`vex` is a command-line tool written in Rust that searches code and engineering context by meaning, not by token. A single binary, no index, no server, no background daemon. Point it at a directory, ask a question in plain English, and get ranked results in under a second.

## The problem it solves

More and more engineering context lives outside the code. The *why* behind a feature is spread across GitHub issues, PR discussions, design docs, and Slack threads that got pasted into a markdown file. A single decision might span a dozen issues, three PRs, and an ADR — and three months later, nobody remembers where the reasoning lives.

Keyword search can't bridge the gap. A search for `retry` misses the issue titled "Resilience strategy for upstream timeouts". A search for `authentication` misses the PR discussion about session handling. The context exists; the vocabulary diverges; `grep` can't find what it doesn't know to look for.

This matters more as codebases grow and teams rely on AI tools to navigate them. If the context can't be found, it can't be used — decisions get repeated, bugs get reintroduced, and tribal knowledge stays tribal.

## How it works

Each query runs a short pipeline:

1. Walk files respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query. Files with zero overlap are dropped.
3. Chunk the top files — tree-sitter for supported languages (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#), paragraph/sliding-window for prose.
4. BM25 pre-filter narrows the pool to the top candidates lexically.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity; return top-k.

Steps 2–4 discard more than 99% of chunks before the neural model sees anything. That is what makes query-time embedding viable without a pre-built index.

## GitHub sync

`vex sync github` materializes issues and PRs as local Markdown files with YAML frontmatter. After a sync, every `vex` query automatically includes them alongside code results. Search for "why did we change the auth flow" and get the PR discussion, the ADR, and the implementation — together, ranked by relevance. Sync is incremental via a watermark; `--force` resets it. No credentials needed for search, only for the sync step itself.

## Getting started

`cargo install --git https://github.com/calumjs/vex` installs the binary. The embedding model (~23 MB) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and for the optional `/vex` [Claude Code](https://claude.com/claude-code) skill — a slash command that teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces ten-to-fifteen grep/glob/read calls from an agent.
