## The problem

Keyword search — `grep`, ripgrep, most editor search — requires you to already know the vocabulary the code uses. On any evolving codebase, that vocabulary drifts. A search for `retry` misses `fetch_with_backoff`. A search for `authentication` misses the PR discussion about session management. The context exists; the words don't match; keyword search can't bridge the gap.

This matters more as codebases grow and as AI tools like Claude Code navigate them on your behalf. If the right context can't be found, decisions get repeated and tribal knowledge stays tribal.

## How it works

Each query runs a short pipeline:

1. Walk files respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query; skip files with no overlap.
3. Chunk the top files — tree-sitter for supported languages (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#), paragraph/sliding-window for prose.
4. BM25 pre-filter narrows to the top candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate more than 99% of chunks before the neural model runs. On a 19,366-file monorepo (Snapdragon X Elite), cold query time is 729ms. No pre-indexing required.

## GitHub sync

`vex sync github` pulls issues and PRs from GitHub into local Markdown files so they appear in every search alongside code:

```bash
vex sync github                        # auto-detect repo from git remote
vex sync github calumjs/vex --force    # full re-sync

# Search synced discussions alongside code
vex "why did we change the auth flow" ~/.local/share/vex/sources/github/owner/repo/
```

Sync is incremental via a watermark stored in `.meta/sync-state.json`. Credentials resolve from `gh auth token` or `GITHUB_TOKEN`. After the initial sync, all search runs locally.

## Claude Code integration

vex ships with a `/vex` [Claude Code](https://claude.com/claude-code) skill that teaches agents to use semantic search effectively — synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces ten to fifteen `grep`/`glob`/`read` calls, saving tokens and context window.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and skill installation instructions.
