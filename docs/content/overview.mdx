## The vocabulary gap

Keyword search assumes you already know what the code calls the thing you're looking for. You usually don't. `rg "retry"` finds the string "retry." `vex "error handling with retries"` finds `fetch_with_retry`, `handle_failure`, and `CircuitBreakerPolicy` — none of which contain the word "retry." The same gap appears in engineering discussions: the issue titled "Resilience strategy for upstream timeouts" doesn't mention "retry" either.

`vex sync github` pulls issues and PRs down as local Markdown under `~/.local/share/vex/sources/github/owner/repo/`. After that, every `vex` search covers code and discussions together — "why did we change the auth flow" returns the PR conversation and the implementation, ranked by relevance, in one shot.

## Pipeline

Each query runs six steps:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`
2. Keyword-score files; files with zero keyword overlap are dropped entirely
3. Chunk the top files via tree-sitter (function/class boundaries for Rust, Python, JS/TS, Go, C, C++, Java, C#) or paragraph/sliding-window for prose
4. BM25 pre-filter narrows to ~50 top candidates
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. Rank by cosine similarity; return top-k

Steps 2–4 eliminate >99% of chunks before the neural model sees anything. That is why query-time embedding is viable without a pre-built index. Benchmarked cold on a Snapdragon X Elite: 468ms on a 585-file .NET codebase, 729ms on a 19k-file monorepo.

Common flags: `-k N` (result count), `-g "*.cs"` (glob filter), `--literal <TERM>` (repeatable keyword boost before ranking — the escape hatch when you already know the vocabulary), `-t 0.3` (similarity floor), `--json`, `--fast` (binary quantization for very large trees), `--device npu` (Hexagon NPU on Snapdragon X Elite).

## Getting started

`cargo install --git https://github.com/calumjs/vex` installs the binary. The embedding model (~23 MB) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup on Windows and Linux/macOS.

The optional `/vex` Claude Code skill (`skills/vex/SKILL.md`) teaches Claude how to use vex effectively — synonym expansion, follow-up queries, flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls from an agent.
