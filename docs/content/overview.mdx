`vex` is a Rust CLI that runs semantic search over code, documentation, and GitHub issues — embedding a natural-language query and the candidates at query time using a local neural model, then ranking by cosine similarity. No index, no server, no background process. A single binary, cold search results in under a second on a 20k-file monorepo.

```
vex "error handling with retries" src/
```

## The vocabulary gap

Keyword search fails when your query and the code don't share the same words. `rg "retry"` misses `fetch_with_retry`, `handle_failure`, and the GitHub issue titled "Resilience strategy for upstream timeouts." All three are relevant; none contain the exact search term.

This gap compounds in AI-assisted workflows. When Claude Code navigates an unfamiliar codebase, it typically fires ten to fifteen `grep`/`glob`/`read` calls and still misses context that lives in a PR discussion or an ADR. `vex` replaces those with one call and includes GitHub issues and PRs in the results when you've synced them.

## The pipeline

Walk files (`.gitignore`-aware) → keyword-score to drop zero-overlap files → tree-sitter-chunk the top 200 by language (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#) → BM25-filter to ~50 candidates → embed query and candidates with `all-MiniLM-L6-v2` (INT8 ONNX, 384-dim) → rank by cosine similarity.

Steps 2–4 eliminate more than 99% of chunks before the neural model runs. That is why query-time embedding is fast enough without pre-indexing.

Run `vex sync github` once to pull issues and PRs as local Markdown under `~/.local/share/vex/sources/github/`. After that, every search includes both the codebase and the engineering context around it.

A Claude Code skill ships at `.claude/skills/vex/SKILL.md`. Invoke it with `/vex` to teach Claude synonym expansion, follow-up queries, and flow tracing — extracting more signal per search call before reading individual files.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup, GitHub sync auth (`gh auth login` is enough), and the optional Claude Code skill install steps.
