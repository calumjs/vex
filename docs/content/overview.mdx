`vex` is a Rust CLI that searches code, docs, and GitHub issues by meaning rather than keywords. No index, no background process; embeddings run at query time against BM25-shortlisted candidates.

```
vex "error handling with retries" src/
```

## The problem

Keyword search assumes you know the vocabulary the code uses. Search for `retry` and miss `fetch_with_retry`. Search for `authentication` and miss the PR discussion about session management. The context exists; the words differ.

This gap matters more on AI-assisted workflows: if an agent can't find the context, it can't use it, and decisions get repeated, bugs get reintroduced, and tribal knowledge stays tribal.

## How it works

Six stages, progressively narrowing the candidate pool:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`
2. Score files by keyword overlap — skip files with no overlap
3. Chunk the top 200 files using tree-sitter for supported languages (Rust, Python, JS, TS, Go, C, C++, Java, C#) or paragraph/sliding-window for prose
4. BM25 pre-filter → top ~50 candidates lexically
5. Embed query + candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. Cosine similarity ranking → top-k

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is what makes query-time embedding viable without pre-indexing: 19,366 files return cold in 729ms on a Snapdragon X Elite.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown files under `~/.local/share/vex/sources/github/owner/repo/`. After that, every `vex` query includes them alongside code, ranked together. Query "why did we change the auth flow" and get the PR discussion and the implementation in one result set.

Sync is incremental via a watermark in `.meta/sync-state.json`; `--force` resets it. Auth resolves in order: `gh auth token`, `GITHUB_TOKEN`, `GH_TOKEN`. Credentials are only used during sync — search runs locally over the materialized Markdown.

## Performance

Benchmarked cold, no pre-indexing, no cache (Snapdragon X Elite, 12-core Oryon, ARM64):

| Codebase | Files | Chunks | Time |
|---|---|---|---|
| Small (.NET app) | 585 | 3,227 | **468ms** |
| Large (monorepo) | 19,366 | 35,579 | **729ms** |

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
vex "database connection pooling" src/
```

The embedding model (~23 MB, INT8 quantized) downloads automatically on first run.
