`vex` is a Rust CLI that searches code and GitHub context by meaning — no index, no server, no background process. A query embeds at run time against the top candidates; a 19,000-file monorepo searches cold in 729ms on a Snapdragon X Elite.

```
vex "database connection pooling" src/
vex "authentication flow" --literal token --literal session -k 5
```

## The problem

`rg "retry"` finds the word "retry." `vex "error handling with retries"` finds `fetch_with_retry`, `handle_failure`, `CircuitBreakerPolicy`, and the design doc explaining the resilience strategy — even when none of them contain the exact word. The vocabulary gap between *how you describe a concept* and *how the code names it* is real, and it widens as teams rely on AI tools to navigate large codebases. If the context cannot be found, it cannot be used.

The same gap extends beyond code. Engineering decisions live in GitHub issues, PR discussions, and architecture docs, not just in `src/`. `vex sync github` materialises them as Markdown under `~/.local/share/vex/sources/github/<owner>/<repo>/`, and every subsequent `vex` search includes them automatically.

## Pipeline

Each query runs six stages:

1. **Walk** files in parallel, respecting `.gitignore` and `.vexignore`
2. **Score** files by keyword overlap — files with zero match are dropped before the neural model runs
3. **Chunk** top files via tree-sitter (Rust, Python, JS/TS, Go, C/C++, Java, C#) or sliding-window for prose
4. **BM25 pre-filter** narrows to the top ~50 candidates
5. **Embed** query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8-quantized) via ONNX Runtime
6. **Rank** by cosine similarity; return top-k

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is what makes query-time embedding viable without pre-indexing.

## Claude Code skill

`.claude/skills/vex/SKILL.md` teaches an agent to open with a broad `vex` query using 3–5 `--literal` synonym hints, read the top-scoring files, then follow up with targeted grep on specific identifiers. One `vex` call typically replaces 10–15 grep/glob/read calls, reducing token and context-window pressure on large codebases.

## Install

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. Install the Claude Code skill globally by copying `.claude/skills/vex/SKILL.md` into `~/.claude/skills/vex/`. See the [README](https://github.com/calumjs/vex) for PATH setup, `--device npu` for Snapdragon X Elite, and the full option reference.
