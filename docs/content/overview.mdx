`vex` is a command-line Rust binary that searches code and GitHub context by meaning. No index, no background process, no daemon. `cargo install --git https://github.com/calumjs/vex` and you're running.

```
vex "error handling with retries" src/
```

That query finds `fetch_with_retry`, `handle_failure`, and `CircuitBreakerPolicy` even if none contain the word "retry". Embedding handles the vocabulary gap; BM25 pre-filtering keeps latency under a second.

## Pipeline

Each query runs six steps:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Keyword-score files against the query. Files with zero overlap are dropped.
3. Chunk the top files — tree-sitter function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph/sliding-window for everything else.
4. BM25 narrows to the top ~50 candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity; return top-k.

Steps 2–4 drop more than 99% of chunks before the model runs. That is what makes query-time embedding viable without a pre-built index — a 19,366-file monorepo returns in 729ms on a Snapdragon X Elite.

## GitHub sync

`vex sync github` materializes issues and PRs as local Markdown under `~/.local/share/vex/sources/github/`. After syncing, every `vex` search includes them alongside code — no separate invocation needed. Subsequent syncs are incremental (watermark in `.meta/sync-state.json`; `--force` to re-fetch everything).

Credentials are resolved in order: `gh auth token`, `GITHUB_TOKEN`, `GH_TOKEN`. Only needed during sync; search runs entirely local.

## Claude Code skill

The repo ships `.claude/skills/vex/SKILL.md` — a `/vex` slash command for Claude Code. It teaches the agent synonym expansion via `--literal` hints, multi-angle follow-up queries, and flow tracing. One `vex` call replaces ten-to-fifteen grep/glob/read calls, conserving context window.

Copy to `~/.claude/skills/vex/` for global availability, or run from within this repo where it loads automatically.

## Install

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. Add `~/.cargo/bin` to `$PATH` on Linux/macOS; on Windows, set it via `[Environment]::SetEnvironmentVariable(...)` in PowerShell.
