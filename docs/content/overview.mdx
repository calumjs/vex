`vex` is a Rust CLI that searches code and engineering context by meaning — query-time embedding over BM25-filtered candidates, no pre-indexing, no server. Point it at a directory, ask in plain English, get ranked results in under a second.

```
vex "error handling with retries" src/
```

## The problem it solves

`grep` and `ripgrep` require you to already know the vocabulary the code uses. Search for `retry` and miss `fetch_with_retry`. Search for `authentication` and miss the PR where the session-management decision was made. The vocabulary gap between what you're looking for and how it was originally described is real, and keyword search can't cross it.

The problem compounds when context lives outside the code — GitHub issues, PR discussions, ADRs. A single architectural decision can span a dozen issues and three PRs. Six months later, none of it surfaces in a keyword search.

`vex` closes both gaps: code and GitHub discussions in one ranked result set, bridged by meaning rather than shared keywords.

## How it works

Each query runs a short pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap — zero-overlap files are dropped immediately.
3. Chunk the top files using tree-sitter (Rust, Python, JS, TS, Go, C, C++, Java, C#) or paragraph splitting for prose.
4. BM25 pre-filter narrows the pool to the top ~50 candidates lexically.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. That's what keeps query-time embedding viable on large trees — a 19,366-file monorepo returns in 729ms cold on a Snapdragon X Elite.

`vex sync github` syncs issues and PRs as local Markdown. After that, every `vex` search includes them automatically alongside code. Search for "why did we change the auth flow" and get the implementation, the PR discussion, and the motivating issue — together, ranked by relevance.

## Getting started

`cargo install --git https://github.com/calumjs/vex` installs the binary. The embedding model (~23 MB, INT8 quantized) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and install details.

vex also ships a `/vex` Claude Code skill that teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls.
