`vex` is a Rust CLI that searches code and engineering context by meaning, not keywords. Point it at a directory, ask a question in plain English, get ranked results in under a second. No index, no server, no background daemon.

```
vex "database connection pooling" src/
```

## The problem

Keyword search — `grep`, `rg`, most editor search — assumes you know the vocabulary the code uses. On real codebases, you often don't. `rg "retry"` misses `fetch_with_backoff`. `rg "authentication"` misses the PR discussion about session handling. Context exists; vocabulary differs; keyword search can't bridge the gap.

The gap widens as engineering decisions spread across GitHub issues, PR discussions, ADRs, and design docs. Three months later, nobody remembers where the reasoning lives. `grep` can't help.

## How it works

Each query runs a six-step pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`
2. Score files by keyword overlap — files with no overlap are dropped
3. Chunk the top 200 files with tree-sitter (Rust, Python, JS, TS, Go, C, C++, Java, C#) or paragraph splitting for prose
4. BM25 pre-filter narrows to ~50 candidates
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. Rank by cosine similarity; return top-k

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is what makes query-time embedding viable — a 19,366-file monorepo returns in 729ms cold, on a Snapdragon X Elite.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/owner/repo/`. Every subsequent `vex` search includes them alongside source files. `vex "why did we change the auth flow"` returns the PR discussion, the architecture doc, and the implementation together, ranked.

Sync is incremental via `.meta/sync-state.json`; `--force` resets the watermark.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup.

`vex` also ships a `/vex` Claude Code skill (`skills/vex/SKILL.md`). Copy it to `~/.claude/skills/vex/` for a slash command that teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces ten-to-fifteen grep/glob/read calls.
