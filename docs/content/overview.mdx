`vex` is a Rust CLI that searches code and engineering context by meaning, not by token. No index, no server, no background process. Install the binary, ask a question in English, get ranked results in under a second.

```
vex "error handling with retries" src/
```

## The vocabulary gap

Keyword search assumes you know the vocabulary the code uses. On real codebases you often don't: a search for `retry` misses `fetch_with_retry`; a search for `authentication` misses the PR discussion about session management. The context exists — the words are different — and `grep` can't bridge that gap.

`vex` closes it by embedding your query and candidate chunks with `all-MiniLM-L6-v2` (384-dim, INT8 quantized via ONNX Runtime) and ranking by cosine similarity. A BM25 pre-filter runs first, discarding >99% of chunks before the neural model sees them. That's why query-time embedding is viable without pre-indexing — a 19,000-file monorepo returns in 729ms cold on a Snapdragon X Elite.

## Code and GitHub context in one search

Run `vex sync github` once to pull issues and PRs into local Markdown under `~/.local/share/vex/sources/github/owner/repo/`. After that, every `vex` search includes them alongside code — search "why did we change the auth flow" and get the PR discussion, the architecture note, and the implementation together, ranked by relevance. Sync is incremental; a watermark in `.meta/sync-state.json` tracks the last fetch.

## The pipeline

1. Walk files respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap — zero-overlap files are dropped.
3. Chunk the top 200 with tree-sitter (Rust, Python, JS, TS, Go, C, C++, Java, C#) or paragraph/sliding-window for prose.
4. BM25 narrows to ~50 candidates.
5. Embed query + candidates; rank by cosine similarity.

Steps 2–4 eliminate most of the search space before the model runs, keeping cold latency under a second without a pre-built index.

## Claude Code integration

`vex` ships with a `/vex` Claude Code skill (`skills/vex/SKILL.md`). Once installed, the agent uses semantic search with synonym expansion, follow-up queries, and flow tracing — typically replacing 10–15 grep/glob/read calls per task.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and optional skill installation.
