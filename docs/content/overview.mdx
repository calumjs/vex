`vex` is a Rust CLI that does semantic search over code, docs, and GitHub issues — using local neural embeddings, no index, no server. A cold query on a 19k-file monorepo returns in ~729ms on an ARM64 laptop (Snapdragon X Elite benchmarks in the README).

```
vex "error handling with retries" src/
```

Results come back as ranked chunks: similarity score, file path and line, source snippet.

## Pipeline

Each query runs a fixed pipeline in `src/`:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`
2. Score files by keyword overlap with the query — zero-overlap files are dropped entirely
3. Chunk the top 200 files — tree-sitter for code (function/class boundaries), paragraph/sliding-window for prose
4. BM25 pre-filter narrows to the top ~50 candidates
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. Rank by cosine similarity, return top-k

Steps 2–4 discard >99% of chunks before the neural model runs. That's what makes query-time embedding viable on large trees.

Supported languages for tree-sitter chunking: Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#. Everything else falls back to prose chunking.

## Flags

`-k N` — result count (default 10). `-t SCORE` — similarity floor. `-g GLOB` — file filter. `--literal TERM` — repeatable keyword boost for vocabulary bridging. `-C LINES` — context lines. `--fast` — binary quantization (~2× faster, less precise). `--device npu|cpu|auto` — inference device. `--json` — machine-readable output.

## GitHub sync

`vex sync github [owner/repo]` materializes issues and PRs as Markdown files under `~/.local/share/vex/sources/github/<owner>/<repo>/` with YAML frontmatter. After sync, every `vex` query automatically searches them alongside code. Subsequent syncs are incremental via a watermark in `.meta/sync-state.json`; `--force` resets it.

Credentials are resolved from `gh auth token`, then `GITHUB_TOKEN`, then `GH_TOKEN`. Only used at sync time — search runs locally.

## Claude Code skill

`/vex` is a slash command (`.claude/skills/vex/SKILL.md`) that teaches Claude Code to use vex effectively: synonym expansion via `--literal`, multi-angle follow-up queries, flow tracing through top results. Replaces ~10–15 grep/glob/read calls per agent task.

Install globally or clone the repo — the skill is automatically available in any Claude Code session within the project directory.

## Install

Requires Rust. `cargo install --git https://github.com/calumjs/vex`. The embedding model (~23 MB quantized) downloads on first run.
