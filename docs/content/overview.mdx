`vex` is a Rust CLI that searches code and engineering context by semantic similarity rather than keyword overlap. No index, no background process. `cargo install --git https://github.com/calumjs/vex` and it runs cold in under a second.

## The vocabulary gap

`grep` and `ripgrep` require you to already know what vocabulary the code uses. In practice, you often don't. The function that handles retries might be named `fetch_with_backoff`. The issue tracking session timeouts might be titled "Resilience strategy for upstream failures." `grep "retry"` misses both.

The same gap compounds in AI-assisted workflows: if context can't be found, it can't be used. Decisions get repeated, bugs reintroduced, tribal knowledge stays tribal. `vex` closes the gap by ranking results on meaning rather than token overlap.

## How it works

Each query runs a six-step pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap — zero-overlap files are dropped early.
3. Chunk the top files via tree-sitter for code (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#) and paragraph/sliding-window for prose.
4. BM25 pre-filter narrows the pool to ~50 candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. Cold query time: 729ms on a 19,366-file monorepo; 468ms on a 585-file .NET codebase (Snapdragon X Elite). `--literal <TERM>` adds a keyword boost pre-ranking for cases where the vocabulary is known; `--fast` enables binary quantization for very large trees.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/owner/repo/` with YAML frontmatter. Sync is incremental (watermark in `.meta/sync-state.json`); `--force` resets it. After syncing, every `vex` query automatically includes them alongside code. Credentials are resolved from `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN` — only sync needs credentials; search is local.

## Claude Code integration

The repo bundles a `/vex` Claude Code skill at `.claude/skills/vex/`. It teaches the agent synonym expansion via `--literal`, multi-angle follow-up queries, and code-flow tracing. Intent: one `vex` call replaces 10–15 grep/glob/read calls.
