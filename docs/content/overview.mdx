`vex` is a Rust CLI that runs semantic search over code, documentation, and synced GitHub issues. Point it at a directory, ask a question in English, get ranked results in under a second. No index, no background process, no setup beyond the install.

```
vex "error handling with retries" src/
```

## The problem

Keyword search — `grep`, `ripgrep`, most editor find — works when you already know the vocabulary the code uses. On any non-trivial codebase, you often don't. A search for `retry` misses `fetch_with_retry`. A search for `authentication` misses the PR discussion titled "session management strategy."

The gap widens as more context moves outside the source tree. A decision spanning three PRs, an ADR, and a GitHub issue thread is unsearchable by keyword; the reasoning exists but can't be found. AI tools like Claude Code are increasingly expected to navigate this context — and if they can't find it, they repeat decisions, reintroduce bugs, and miss the engineering history that should inform new work.

## How it works

Each query runs a short pipeline:

1. Walk files, respecting `.gitignore` and `.vexignore`
2. Score files by keyword overlap with the query; drop files with zero overlap
3. Chunk the top files — tree-sitter boundaries for Rust, Python, JS/TS, Go, C, C++, Java, C#; paragraph splits for prose
4. BM25 pre-filter narrows to the top candidates lexically
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. Rank by cosine similarity; return top-k

Steps 2–4 drop >99% of chunks before the neural model runs. That is what makes query-time embedding viable without an index: cold search on a 19,366-file monorepo completes in 729ms on a Snapdragon X Elite.

GitHub issues and PRs enter the same pipeline via `vex sync github`, which materializes them as Markdown under `~/.local/share/vex/sources/github/owner/repo/`. After a sync, every query automatically includes them alongside code. Incremental sync uses a watermark in `.meta/sync-state.json`; `--force` resets it.

## Getting started

Requires Rust. Install with:

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. [See the README for PATH setup and full usage](https://github.com/calumjs/vex).

The `/vex` Claude Code skill is included in the repo. Installed globally, it teaches the agent synonym expansion, follow-up queries, and flow tracing — one `vex` call replacing 10–15 grep/glob/read calls.
