`vex` is a CLI that runs semantic search over code, docs, and GitHub issues at query time. No index, no background process. `cargo install --git https://github.com/calumjs/vex`, run `vex "your question" src/`, get ranked results in under a second.

## The problem

Keyword search assumes vocabulary alignment between query and source. On real codebases — and especially across the code-plus-discussion layer — this fails routinely. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR discussion titled "Session management strategy." The implementation and the reasoning that motivated it rarely share a word.

This matters more as codebases grow and teams rely on AI coding agents. Claude Code navigates a codebase through file reads and searches; if a relevant file is hard to surface with keyword queries, the context stays missing and decisions get repeated or bugs reintroduced.

## How it works

vex runs a six-step pipeline at query time:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query — files with no overlap are dropped.
3. Chunk the top files using tree-sitter (Rust, Python, JS, TS, Go, C, C++, Java, C#) or paragraph splitting for prose.
4. BM25 pre-filter narrows to the top candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime on CPU.
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. A 19k-file monorepo returns cold in 729ms on a Snapdragon X Elite. No pre-built index makes that possible.

For the GitHub layer: `vex sync github` materializes issues and PRs as Markdown with YAML frontmatter under `~/.local/share/vex/sources/github/owner/repo/`. After that, every `vex` search includes them automatically. Query "why did we change the auth flow" and get the PR discussion alongside the implementation, ranked by relevance.

The `/vex` Claude Code skill (`skills/vex/SKILL.md`) teaches the agent to use vex with synonym expansion (`--literal`), follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls.

## Getting started

Requires Rust. See the [README](https://github.com/calumjs/vex#install) for PATH setup, the optional Claude Code skill, and sync options. The embedding model (~23 MB, quantized) downloads automatically on first run.
