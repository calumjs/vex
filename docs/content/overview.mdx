## The problem

Keyword search assumes you know the vocabulary. On any non-trivial codebase you often don't. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR that renamed sessions to tokens. The gap between your intent and the code's vocabulary is where keyword search fails.

GitHub context compounds this. The rationale for a design decision might live in a closed issue, a merged PR, or an ADR in `docs/` — all using different terms than the code it motivated. `grep` can't span that.

## How it works

`vex` runs a six-step pipeline at query time:

1. Walk files in parallel (`.gitignore`-aware; `.vexignore` for extras).
2. Score files by query keyword overlap — zero-overlap files are dropped.
3. Chunk the top 200 files with tree-sitter (function/class boundaries) or paragraph splitting for prose.
4. BM25 pre-filter → top ~50 candidates.
5. Embed query + candidates with [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) (384-dim, INT8 quantized) via ONNX Runtime.
6. Cosine rank → top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. This is why no pre-indexing is required — it's fast enough to embed cold.

**GitHub sync** (`vex sync github`) pulls issues and PRs into local Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/`. Every subsequent `vex` query includes them alongside code, ranked by relevance. Credentials (via `gh auth`, `GITHUB_TOKEN`, or `GH_TOKEN`) are only needed at sync time; search is local.

Supported tree-sitter languages: Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#. Everything else falls back to paragraph/sliding-window chunking.

## Getting started

[Install instructions and all CLI flags are in the README.](https://github.com/calumjs/vex#install) Short version:

```bash
cargo install --git https://github.com/calumjs/vex
vex "database connection pooling" src/
```

The embedding model (~23 MB quantized) downloads automatically on first run. `vex` also ships a `/vex` Claude Code skill in `.claude/skills/vex/` that teaches the agent synonym expansion, follow-up queries, and flow tracing — available in any Claude Code session inside the repo.
