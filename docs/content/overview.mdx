`vex` is a Rust CLI that searches code and engineering context by meaning instead of keywords. No index, no background process, no configuration. Point it at a directory and ask a question in plain English.

```
vex "error handling with retries" src/
```

## The vocabulary gap

`grep` and `ripgrep` match exact strings. When the code uses `fetch_with_retry` and the query says `retry`, they connect. When the code uses `CircuitBreakerPolicy` and the query says "resilience strategy," they don't.

The gap widens as engineering context spreads across GitHub issues, PR discussions, and design docs. A decision to change the auth flow might live in a PR from three months ago — keyword search can't surface it unless you already know the words it used.

`vex` closes the gap by embedding query and code at query time using a local INT8-quantized `all-MiniLM-L6-v2` model (384-dim) via ONNX Runtime. A BM25 pre-filter discards >99% of chunks before the model runs, making cold query-time embedding viable — 468ms for a 585-file codebase, 729ms for a 19k-file monorepo on a Snapdragon X Elite.

## The pipeline

Each query:

1. Walks files respecting `.gitignore` and `.vexignore`
2. Scores files by keyword overlap — skips files with zero overlap
3. Chunks the top 200 files using tree-sitter (Rust, Python, JS/TS, Go, C, C++, Java, C#) or paragraph splitting for prose
4. BM25 pre-filter narrows to ~50 candidates
5. Embeds query + candidates with the quantized model
6. Ranks by cosine similarity, returns top-k

## GitHub sync

`vex sync github` materializes issues and PRs as local Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/`. After sync, every `vex` query includes them alongside code with no extra flags. Credentials resolve via `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN` — only needed for sync, not for search. Subsequent syncs are incremental via a watermark in `.meta/sync-state.json`.

## Claude Code skill

The repo ships a `/vex` slash command at `.claude/skills/vex/SKILL.md`. It instructs Claude to use synonym expansion, follow-up queries, and flow tracing — one `vex` call typically replaces 10–15 grep/glob/read calls from an agent. Copy it globally or leave it in-repo; it activates automatically in any Claude Code session.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8-quantized) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and optional skill installation.
