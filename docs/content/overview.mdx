## The problem

Keyword search assumes you know the vocabulary the code uses. `grep "retry"` won't find `fetch_with_retry`. `grep "auth"` won't find the PR discussion titled "Session management overhaul" or the issue about token expiry. The implementation and the reasoning behind it are both in the repo — at different vocabulary coordinates.

The gap widens as engineering context accumulates outside the source tree. GitHub issues, PR threads, architecture docs that got pasted into Markdown — none of these surface in a `rg` run. Teams using AI coding tools feel this sharply: the agent searches, comes up empty, then asks the developer to paste context that already exists somewhere in the repo.

## How `vex` works

Query pipeline: walk files → keyword-score candidates → chunk with tree-sitter (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#) or prose-split → BM25 narrow → embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized, ONNX Runtime) → rank by cosine similarity.

Steps 2–4 eliminate more than 99% of candidates before the neural model runs. That's why there's no indexing step: embedding at query time is fast enough when you've already discarded most of the corpus.

Measured on Snapdragon X Elite: 468 ms on a 585-file codebase, 729 ms cold on a 19,366-file monorepo.

**GitHub issues and PRs.** `vex sync github` pulls issues and PRs down as local Markdown. Subsequent searches include them automatically — implementation and the discussion that motivated it, ranked together.

**Claude Code skill.** `/.claude/skills/vex/SKILL.md` ships a `/vex` slash command that instructs Claude to expand queries with `--literal` keyword hints, run follow-up queries from different angles, and trace call chains from top results. One `vex` call typically replaces 10–15 grep/glob/read calls.

## Getting started

Requires [Rust](https://rustup.rs/):

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and the optional Claude Code skill install.
