`vex` is a Rust CLI that searches code, docs, and synced GitHub issues by semantic similarity rather than token overlap. Single binary, no index, no server, no daemon — the full embedding pipeline runs at query time.

## The problem

`grep` and `ripgrep` match tokens. Engineering context doesn't always use the same tokens as your query. A search for `retry` misses `fetch_with_retry` and `handle_failure`. A search for `authentication` misses the PR titled "Resilience strategy for session management." As teams lean on AI tools like Claude Code to navigate codebases, vocabulary gaps compound — context that can't be found can't be used, and decisions get repeated.

## How it works

Each query runs a six-step pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap; skip files with zero overlap.
3. Chunk the top 200 files — tree-sitter at function/class boundaries for supported languages (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#), paragraph/sliding-window for prose.
4. BM25 pre-filter narrows to the top ~50 candidates lexically.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime on CPU.
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate > 99% of chunks before the neural model runs. On a 19,366-file monorepo (Snapdragon X Elite, 12-core Oryon), cold latency is 729ms. No cache. No pre-index.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/` with YAML frontmatter. Sync is incremental — a watermark in `.meta/sync-state.json` tracks what's been fetched; `--force` resets it. After sync, every `vex` query spans code and issue/PR discussions together, ranked by relevance.

## Claude Code skill

`.claude/skills/vex/SKILL.md` is a `/vex` slash command for Claude Code. It instructs Claude to expand queries with synonym `--literal` hints, run follow-up queries from multiple angles, and trace code flow from results. One `vex` call in an agentic loop typically replaces 10–15 grep/glob/read calls. Copy `SKILL.md` to `~/.claude/skills/vex/` for global availability.

## Install

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup and full CLI reference (`-k`, `-g`, `--literal`, `-t`, `--json`, `--fast`, `--device npu`).
