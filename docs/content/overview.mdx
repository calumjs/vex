`vex` is a Rust CLI that searches code and GitHub issues by meaning. Single binary, no pre-indexing, no server. Query at runtime with a local embedding model; get ranked results in under a second.

```
vex "error handling with retries" src/
```

## The problem

`grep` and `rg` require exact vocabulary — you can only find what you already know to search for. On any nontrivial codebase, `fetch_with_retry` doesn't surface when you search `retry`; the PR discussing "resilience strategy for upstream timeouts" stays dark when you search `timeout`. As codebases grow and AI agents work through them, unfound context gets repeated, not reused.

`vex` bridges the vocabulary gap. It embeds both the query and code chunks with `all-MiniLM-L6-v2` at query time, ranks by cosine similarity, and returns matches by meaning. Run `vex sync github` once to pull issues and PRs into local Markdown; every subsequent search includes them alongside the code.

## How it works

Each query runs a six-step pipeline in the current binary:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap — zero-overlap files drop immediately.
3. Chunk the top files via tree-sitter (Rust, Python, JS/TS, Go, C, C++, Java, C#) or sliding-window for prose.
4. BM25 pre-filter → top candidates.
5. Embed query + candidates: `all-MiniLM-L6-v2`, 384-dim INT8 quantized, via ONNX Runtime.
6. Cosine similarity → top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs — that's what makes query-time embedding viable without pre-indexing. Benchmarked on Snapdragon X Elite: 468 ms cold on a 585-file .NET project, 729 ms on a 19 k-file monorepo.

## Getting started

Install with `cargo install --git https://github.com/calumjs/vex`. The embedding model (~23 MB, INT8 quantized) downloads automatically on first run. For the optional Claude Code integration, the `/vex` skill teaches Claude synonym expansion, follow-up queries, and flow tracing — one `vex` call typically replaces 10–15 grep/glob/read calls from an agent. [Full install and usage in the README](https://github.com/calumjs/vex#install).
