`vex` is a Rust CLI that searches code and engineering context by embedding — no index, no server, results in under a second.

```
vex "error handling with retries" src/
```

## The problem

Keyword search fails the vocabulary gap. `rg "retry"` misses `fetch_with_retry`. `grep "authentication"` misses the PR discussion about session management. The code and the context exist; the words differ. On any real codebase this is routine friction, and on AI-assisted workflows it compounds: if an agent can't retrieve the context, it can't use it.

## How vex works

The query pipeline runs client-side, cold, on every invocation:

1. Walk files (`.gitignore`-aware, parallel)
2. Score files by keyword overlap with the query — zero-overlap files are dropped entirely
3. Chunk the top 200 files: tree-sitter at function/class boundaries for Rust, Python, JS/TS, Go, C, C++, Java, C#; paragraph/sliding-window for prose
4. BM25 pre-filter narrows to ~50 candidates lexically
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. Rank by cosine similarity, return top-k

Steps 2–4 drop >99% of chunks before the neural model sees anything. That's what makes query-time embedding viable: a 19k-file monorepo returns cold in 729ms on a Snapdragon X Elite. No pre-indexing means no stale index, no sync step, no background daemon.

## GitHub sync

`vex sync github` pulls issues and PRs down as local Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/`. After that, every `vex` search automatically includes them alongside code — querying "why did we change the auth flow" surfaces the PR discussion and the implementation together, ranked by relevance. Sync is incremental via `.meta/sync-state.json`; `--force` re-fetches everything.

Auth resolves in order: `gh auth token`, `GITHUB_TOKEN`, `GH_TOKEN`. Credentials are only used during sync; search runs locally over materialized Markdown.

## Claude Code skill

vex ships with a `/vex` slash command in `.claude/skills/vex/SKILL.md`. The skill teaches Claude how to use semantic search effectively: synonym expansion via `--literal`, follow-up queries from different angles, and call-site tracing. One `vex` call typically replaces ten-to-fifteen grep/glob/read calls from an agent, with meaningful context-window savings on large codebases.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads on first run. [See the README](https://github.com/calumjs/vex) for PATH setup, all CLI flags, and the optional Claude Code skill install.
