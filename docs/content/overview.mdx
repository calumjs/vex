`vex` is a Rust CLI for semantic search over code and GitHub issues. Single binary, no index, no server, no background daemon. Sub-second cold queries on a 19k-file monorepo.

```
vex "error handling with retries" src/
```

## The problem

Engineering context is scattered. The *why* behind a feature spans GitHub issues, PR discussions, design docs, and pasted Slack threads. Keyword search can't bridge the vocabulary gap: `rg "retry"` misses `fetch_with_backoff`. `grep "authentication"` misses the PR titled "Resilience strategy for upstream timeouts." The context exists; the terms are different.

This compounds as AI tools (Claude Code, Cursor) navigate codebases on behalf of developers. If the context can't be found, it won't be used — decisions repeat, bugs reappear, tribal knowledge stays tribal.

## How it works

Each query runs a six-step pipeline:

1. **Walk** — parallel file traversal, `.gitignore`- and `.vexignore`-aware.
2. **Score** — keyword overlap filter; zero-overlap files are dropped immediately.
3. **Chunk** — tree-sitter for Rust, Python, JS/TS, Go, C/C++, Java, C#; paragraph/sliding-window for prose.
4. **BM25 pre-filter** — narrows to top ~50 candidates lexically.
5. **Embed** — `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime on CPU (or `--device npu` on Snapdragon X Elite's Hexagon NPU).
6. **Rank** — cosine similarity; return top-k.

Steps 2–4 discard >99% of chunks before the neural model runs. That is why query-time embedding is viable: a 585-file .NET app returns in 468ms; a 19k-file monorepo in 729ms. No pre-indexing. No cache.

## GitHub sync

`vex sync github` pulls issues and PRs down as local Markdown files (default: `~/.local/share/vex/sources/github/<owner>/<repo>/`). After that, every `vex` query automatically includes them. Search for "why did we change the auth flow" and get the PR discussion, the architecture doc, and the implementation — ranked together. Subsequent syncs are incremental (watermark in `.meta/sync-state.json`). Auth resolves via `gh auth token` → `GITHUB_TOKEN` → `GH_TOKEN`.

## AI workflow integration

`vex` ships with a `/vex` Claude Code skill (`skills/vex/SKILL.md`). Install it globally (`~/.claude/skills/vex/`) or it's auto-available within this repo. The skill teaches the agent to expand queries with `--literal` synonym hints, run multi-angle follow-ups, and trace code flow from results. One `vex` call typically replaces 10–15 grep/glob/read calls, saving context window and tokens.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads on first run. Full CLI reference and PATH setup at [github.com/calumjs/vex](https://github.com/calumjs/vex).
