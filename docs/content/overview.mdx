`vex` is a Rust CLI binary that runs semantic search over a source tree at query time — no pre-index, no background process, single binary. It embeds your query and the code on each invocation, ranks by cosine similarity, and returns results in under a second.

## The problem it solves

Keyword search assumes you know the vocabulary the code uses. On real codebases you often don't. `grep "retry"` misses `fetch_with_retry`. `grep "authentication"` misses the PR discussion titled "Resilience strategy for upstream timeouts." The context exists; the words don't match.

```bash
vex "error handling with retries" src/
```

That query returns `fetch_with_retry` in `src/client.rs`, `handle_failure` in `src/worker.rs`, and any design doc explaining the resilience strategy — ranked by relevance, without any of them containing the word "retry."

## How it works

Each query runs a six-step pipeline: walk files respecting `.gitignore` and `.vexignore`; score by keyword overlap and discard zero-overlap files; chunk top files with tree-sitter at function/class boundaries (Rust, Python, JS/TS, Go, C, C++, Java, C#), paragraph splitting for prose; BM25 pre-filter to the top candidates; embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8) via ONNX Runtime; rank by cosine similarity.

Steps 2–4 discard >99% of chunks before the neural model runs. Cold search on a 19k-file monorepo takes 729ms on a Snapdragon X Elite.

**GitHub sync.** `vex sync github` pulls issues and PRs down as local Markdown under `~/.local/share/vex/sources/github/`. Every subsequent query returns issues and implementation together, ranked together.

**Claude Code skill.** `.claude/skills/vex/SKILL.md` ships a `/vex` slash command that teaches Claude synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read calls.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
vex "database connection pooling" src/
```

Requires Rust. The embedding model (~23 MB quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup, NPU configuration (`--device npu`), and GitHub sync credentials.
