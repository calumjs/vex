`vex` is a Rust CLI for semantic code search. No server, no index, no background process. Ask a question in plain English; get ranked results from your codebase and synced GitHub issues/PRs in under a second.

## The problem

`grep` and `ripgrep` require vocabulary-match. On any real codebase, you often don't know the vocabulary the code uses. `vex "error handling with retries"` finds `fetch_with_retry`, `handle_failure`, and `CircuitBreakerPolicy` — none of which contain the word "retry." The same gap applies to GitHub discussions: `rg "authentication"` misses the PR titled "Session management overhaul."

Engineering context accumulates in issues, PR threads, design docs, and ADRs. Three months later, nobody remembers which PR records why the auth flow changed. `vex sync github` pulls issues and PRs to disk as Markdown; every subsequent `vex` query searches them alongside code automatically.

## How it works

Six-step pipeline: walk files (`.gitignore`/`.vexignore`-aware), score by keyword overlap (discarding zero-overlap files), chunk with tree-sitter for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C# — or sliding-window for prose — BM25 pre-filter to the top candidates, embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8) via ONNX Runtime, rank by cosine similarity.

Steps 2–4 discard >99% of chunks before the neural model runs. Cold results in 468ms on a 585-file .NET codebase; 729ms on a 19,366-file monorepo (Snapdragon X Elite). No pre-indexing.

```
vex "database connection pooling" src/
vex "error handling with retries" --literal retry --literal backoff
vex "why did we change the auth flow" ~/.local/share/vex/sources/github/owner/repo/
```

Key flags: `-k N` (result count), `-g "*.cs"` (glob filter), `--literal <term>` (keyword boost, repeatable), `-t 0.3` (similarity floor), `-C 5` (context lines), `--json` (machine output), `--fast` (binary quantization on large trees).

## Getting started

Requires [Rust](https://rustup.rs/):

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup.

A `/vex` Claude Code skill ships with the repo — install it globally and agents call `vex` instead of chains of grep/glob/read. One `vex` call typically replaces 10–15 agent tool calls.
