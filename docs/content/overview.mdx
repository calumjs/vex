`vex` is a Rust CLI for semantic search across code and GitHub issues. Pass a plain-English query; it returns ranked chunks from any directory in under a second. No index, no server, no daemon — embedding happens at query time via `all-MiniLM-L6-v2` (384-dim, INT8 ONNX) backed by a BM25 pre-filter that keeps the neural pass cheap.

## The vocabulary gap

`rg "retry"` finds the word "retry". `vex "error handling with retries"` finds `fetch_with_retry`, `handle_failure`, and the issue titled "Resilience strategy for upstream timeouts" — even when none of them contain "retry". This matters on any project where the person navigating the code didn't name it, and on any query where you know the concept but not the vocabulary.

The gap extends outside the code. `vex sync github` pulls issues and PRs down as Markdown under `~/.local/share/vex/sources/github/owner/repo/`; after that, every search includes them automatically. Query "why did the auth flow change" and get the implementation, the issue, and the PR discussion — ranked together.

## Pipeline

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`
2. Score by keyword overlap — skip files with zero overlap
3. Chunk the top files: tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph splits for prose
4. BM25 pre-filter → top ~50 candidates
5. Embed query + candidates via `all-MiniLM-L6-v2` (ONNX Runtime, INT8)
6. Rank by cosine similarity; return top-k

Steps 2–4 eliminate >99% of chunks before the model runs. A 19k-file monorepo returns cold in 729ms on a Snapdragon X Elite.

Flags: `-k N` (result count), `-g "*.cs"` (glob filter), `--literal <term>` (keyword boost before ranking, repeatable), `-t 0.3` (similarity floor), `--json`, `--fast` (binary quantization, ~2× faster, less precise), `--device npu` (Snapdragon X Elite Hexagon NPU).

## Getting started

`cargo install --git https://github.com/calumjs/vex` — the embedding model (~23 MB, INT8 quantized) downloads on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup.

The optional `/vex` Claude Code skill lives at `.claude/skills/vex/SKILL.md`. Copy it to `~/.claude/skills/vex/` for global availability. It teaches agents synonym expansion, follow-up query patterns, and flow tracing; one `vex` call typically replaces 10–15 grep/glob/read calls.
