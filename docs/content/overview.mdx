## The problem

Keyword search — `grep`, `ripgrep`, most editor search — assumes you already know the vocabulary the code uses. You search for `retry` and miss `fetch_with_retry`. You search for `authentication` and miss the PR discussion about session management. More broadly: the *why* behind a feature scatters across GitHub issues, PR threads, design docs, and ADRs. Three months later, nobody knows where the reasoning lives, and context that was captured gets treated as lost.

This gap is amplified in AI-assisted workflows. An agent that can't find the relevant context can't use it — decisions get repeated, bugs get reintroduced, tribal knowledge stays tribal.

## How vex solves it

vex embeds your query and candidate chunks at query time with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime, then ranks by cosine similarity. A BM25 pre-filter runs first to eliminate >99% of chunks before the neural model sees anything — that is what makes query-time embedding viable without a pre-built index.

The pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query. Zero-overlap files are dropped.
3. Chunk the top files — tree-sitter (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#) for code; paragraph/sliding-window for prose.
4. BM25 pre-filter narrows the pool to ~50 top candidates.
5. Embed query and candidates.
6. Rank by cosine similarity, return top-k.

On a 19,366-file monorepo, cold query time is 729 ms on a Snapdragon X Elite. Small projects return under 500 ms. No pre-indexing. No cache. Cold every time.

## GitHub sync

`vex sync github` materializes issues and PRs as local Markdown with YAML frontmatter under `~/.local/share/vex/sources/github/owner/repo/`. Once synced, every `vex` search includes them automatically — no separate path needed. Search for "why did we change the auth flow" and find the implementation, the PR discussion, and any linked issues, ranked together.

Credentials resolve in order: `gh auth token`, then `GITHUB_TOKEN`, then `GH_TOKEN`. Sync is incremental via a watermark in `.meta/sync-state.json`; `--force` re-fetches everything. Pass `--include issues,prs`, `--state open`, `--labels bug,critical`, or `--limit N` to narrow what gets pulled.

## Claude Code skill

vex ships with a `/vex` slash command for [Claude Code](https://claude.com/claude-code). Install it globally or clone the repo and it's available in any session within it. The skill teaches the agent synonym expansion using `--literal` hints, multi-angle follow-up queries, flow tracing through results, and how to combine vex with grep for a complete picture. One `vex` call typically replaces ten to fifteen grep/glob/read calls, saving tokens and context window.
