## The problem

Engineering context is scattered. A decision lands in a GitHub issue, a PR discussion, a design doc, and a Markdown-pasted Slack thread — and six months later nobody remembers which. `grep` and `rg` only find what you already know to search for: "retry" misses `fetch_with_retry`, "authentication" misses the PR about session management. The vocabulary gap between *what you're looking for* and *how it was written* is the failure mode keyword search can't address.

This matters especially in AI-assisted workflows. If Claude Code can't find the relevant context, it repeats decisions, reintroduces bugs, and invents answers the repo already has.

## Pipeline

Each query runs six steps:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query — zero-overlap files are dropped.
3. Chunk the survivors: tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph/sliding-window for prose.
4. BM25 pre-filter narrows the pool to ~50 candidates.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8, ONNX Runtime).
6. Rank by cosine similarity; return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model runs. That's what makes query-time embedding viable without pre-indexing: a 19,366-file monorepo returns in 729ms cold on a Snapdragon X Elite.

## GitHub sync

`vex sync github` pulls issues and PRs into local Markdown under `~/.local/share/vex/sources/github/owner/repo/`. After that, every `vex` search includes them alongside code automatically — "why did we change the auth flow" returns the PR discussion, the ADR, and the implementation together. Sync is incremental (watermark in `.meta/sync-state.json`); `--force` re-fetches everything. Credentials resolve from `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN` — only used during sync.

## Claude Code skill

vex ships a `/vex` slash command for [Claude Code](https://claude.com/claude-code) (`skills/vex/SKILL.md`) that teaches synonym expansion, follow-up queries, and flow tracing. One `vex` call replaces 10–15 grep/glob/read calls, cutting token spend and context-window pressure.
