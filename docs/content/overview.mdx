`vex` is a Rust CLI that searches code and GitHub context by meaning, not keyword matching. No index, no daemon, no config. `cargo install --git https://github.com/calumjs/vex` and it's ready.

```
vex "error handling with retries" src/
```

Returns `fetch_with_retry`, `handle_failure`, and `CircuitBreakerPolicy` even if none of them contain the word "retry" — the query and candidates are embedded with `all-MiniLM-L6-v2` (INT8-quantized via ONNX Runtime) and ranked by cosine similarity.

## The problem

Keyword search assumes you already know the vocabulary the code uses. On real codebases, you often don't. `grep "retry"` misses `fetch_with_backoff`. `grep "authentication"` misses the PR discussion that settled on session management. The context exists; the words diverged; `grep` can't bridge that.

This matters more as AI tools like Claude Code become load-bearing. If context can't be retrieved, it can't be used — decisions repeat, bugs resurface, and tribal knowledge stays tribal.

## Pipeline

1. **Walk** — file scan respecting `.gitignore` and `.vexignore`
2. **Score** — keyword overlap filter; drops zero-overlap files
3. **Chunk** — tree-sitter (Rust, Python, JS/TS, Go, C, C++, Java, C#) or paragraph splits for prose
4. **BM25** — pre-filter to top candidates lexically
5. **Embed** — `all-MiniLM-L6-v2`, 384-dim INT8, ONNX Runtime; CPU by default, NPU on Snapdragon X Elite
6. **Rank** — cosine similarity, return top-k

Steps 2–4 drop >99% of chunks before the model sees them. That is why query-time embedding is viable without a pre-built index: 729ms cold on a 19,366-file monorepo.

## GitHub sync

`vex sync github` materializes issues and PRs as local Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/`. After that, every `vex` search includes them alongside code — search "why did we remove the cache" and find the PR discussion, the commit, and the ADR together, ranked by relevance. Syncs are incremental via a watermark in `.meta/sync-state.json`; `--force` resets it.

## Claude Code skill

The `/vex` skill ships with the repo. It instructs Claude to run synonym-expanded queries, follow up from multiple angles, trace code flow, and combine with grep. One `vex` call typically replaces 10–15 grep/glob/read calls, saving tokens and context window.

## Getting started

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run. Add `~/.cargo/bin` to PATH. The `/vex` Claude Code skill is available in any session inside the repo, or copy `.claude/skills/vex/SKILL.md` to `~/.claude/skills/vex/` for global use.
