## The problem

Keyword search assumes you already know the vocabulary the code uses. On any non-trivial codebase, you often don't. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR thread titled "Session management redesign." The context exists; the words differ; grep can't bridge the gap.

The problem compounds with AI-assisted workflows. If Claude Code can't find the relevant context — the ADR, the issue thread, the function — it can't use it. Decisions get repeated, bugs get reintroduced, tribal knowledge stays tribal.

## Pipeline

`vex` runs six stages at query time:

1. **Walk** files in parallel, respecting `.gitignore` and `.vexignore`.
2. **Keyword score** — skip files with no query-term overlap entirely.
3. **Chunk** the top 200 files at tree-sitter boundaries (function/class for code; paragraphs for prose/markdown).
4. **BM25 pre-filter** — narrow to the top ~50 candidates lexically before embedding.
5. **Embed** query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime, multithreaded.
6. **Rank** by cosine similarity, return top-k.

Steps 2–4 eliminate >99% of chunks before the neural model sees them. That's what makes query-time embedding viable without a pre-built index.

Tree-sitter chunking is supported for: Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#. All other text files fall back to paragraph/sliding-window chunking.

## GitHub sync

`vex sync github` fetches issues and PRs as local Markdown files with YAML frontmatter into `~/.local/share/vex/sources/github/owner/repo/`. After the first sync, every `vex` query can include them:

```bash
vex sync github
vex "why did we change the auth flow" src/ ~/.local/share/vex/sources/github/calumjs/vex/
```

Subsequent syncs are incremental — only items updated since the watermark in `.meta/sync-state.json` are re-fetched. Credentials resolve from `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN`, and are only used during sync; search runs entirely offline.

## Claude Code skill

`vex` ships with a `/vex` slash command for Claude Code (`skills/vex/SKILL.md`). The skill instructs Claude to expand queries with `--literal` hints, run follow-up queries from different angles, trace code flow across top results, and combine `vex` with grep for complete coverage. A single `/vex` invocation replaces 10–15 manual tool calls.

## Getting started

Requires Rust (`rustup.rs`). Install directly from GitHub:

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads on first run. [See the README](https://github.com/calumjs/vex#install) for PATH setup on Windows and the full option reference.
