`vex` is a Rust CLI that searches code and engineering context by meaning rather than token match. One binary, no index, no server, sub-second cold results.

```
vex "error handling with retries" src/
```

## The problem

`grep` and `ripgrep` assume you know the vocabulary the code uses. `vex "error handling with retries"` finds `fetch_with_retry`, `handle_failure`, and `CircuitBreakerPolicy` — none of which contain the word "retry." Engineering context scattered across GitHub issues, PRs, and ADRs has the same problem: the vocabulary gap widens when a decision and its implementation are authored months apart by different people.

## Pipeline

Each query runs six steps:

1. **Walk** files in parallel (`.gitignore`/`.vexignore`-aware).
2. **Keyword score** — files with zero overlap with the query are dropped.
3. **Chunk** top files at function/class boundaries via tree-sitter (Rust, Python, JS, TS, Go, C, C++, Java, C#); paragraph/sliding-window for prose and other types.
4. **BM25 pre-filter** → top ~50 candidates lexically.
5. **Embed** query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. **Rank** by cosine similarity, return top-k.

Steps 2–4 discard >99% of chunks before the neural model runs. A 19,366-file monorepo returns cold in 729ms on a Snapdragon X Elite. This is what makes query-time embedding viable without pre-indexing.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown files under `~/.local/share/vex/sources/github/owner/repo/` with YAML frontmatter. After a sync, every `vex` search includes them automatically alongside code. Sync is incremental; `.meta/sync-state.json` holds the watermark. Credentials resolve from `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN` — only used during sync, not search.

## Claude Code skill

`/vex` (`skills/vex/SKILL.md`) teaches Claude Code to use semantic search effectively: synonym expansion via `--literal` hints, follow-up queries from different angles, and code flow tracing. One `vex` call replaces 10–15 grep/glob/read calls, reducing token consumption and context window pressure in agentic workflows.

## Install

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads on first run. Add `~/.cargo/bin` to `PATH`. See the [README](https://github.com/calumjs/vex#install) for platform-specific PATH instructions.
