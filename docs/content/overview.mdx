`vex` is a command-line tool for searching code and engineering context by meaning rather than by token. It runs a local embedding pipeline at query time — no pre-built index, no background daemon. Point it at a directory, ask a question in plain English, and get ranked results in under a second.

## The problem

Keyword search assumes you know the vocabulary the code uses. You rarely do. `rg "retry"` misses `fetch_with_retry`. `grep "authentication"` misses the PR discussion titled "Session management strategy." The context exists; the words diverge; keyword search can't cross that gap.

This matters more when AI tools like Claude Code navigate the codebase on your behalf. If context can't be surfaced, it can't be used — decisions get repeated, bugs get reintroduced, tribal knowledge stays tribal.

## How it works

Each query runs a short pipeline:

1. Walk files in parallel, respecting `.gitignore` and `.vexignore`
2. Score files by keyword overlap — files with no match are dropped
3. Chunk the top 200 files — tree-sitter at function/class boundaries for Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#; paragraph splitting for everything else
4. BM25 pre-filter narrows to ~50 candidates
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime
6. Rank by cosine similarity

Steps 2–4 eliminate >99% of chunks before the neural model runs. That's what makes query-time embedding viable: a small .NET app benchmarks at 468ms cold; a 19k-file monorepo at 729ms.

```bash
# Find retry logic without knowing the function names
vex "error handling with retries" src/

# Pin a keyword boost for vocabulary bridging
vex "code that prevents race conditions" --literal lock --literal mutex

# Constrain to a specific language
vex "validation logic" -g "*.cs"
```

## GitHub issues in the same search

`vex sync github` materializes issues and PRs as local Markdown under `~/.local/share/vex/sources/github/owner/repo/`. After that, every `vex` search includes them automatically alongside code. Search "why did we change the auth flow" and get the PR discussion, the architecture note, and the implementation together, ranked by relevance. Sync is incremental; `--force` resets the watermark. Auth resolves from `gh auth token`, then `GITHUB_TOKEN`, then `GH_TOKEN`.

## Getting started

[Install Rust](https://rustup.rs/), then:

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB, INT8 quantized) downloads on first run. See the [README](https://github.com/calumjs/vex) for PATH setup, the full option reference, and the optional `/vex` Claude Code skill — a slash command that teaches agents to use vex effectively (synonym expansion, follow-up queries, flow tracing).
