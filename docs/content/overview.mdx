## What it solves

Keyword search (`grep`, `ripgrep`) assumes the vocabulary in your query matches the vocabulary in the code. It usually doesn't. `retry` misses `fetch_with_backoff`. `authentication` misses the PR discussion titled "Resilience strategy for upstream timeouts."

The gap widens when engineering context is spread across code, GitHub issues, ADRs, and old PR threads. Especially relevant for AI-assisted workflows: if Claude Code can't surface the relevant context, it can't use it.

`vex` embeds the query and candidate chunks with a local neural model (`all-MiniLM-L6-v2`, INT8 quantized, ~23 MB) and ranks by cosine similarity. No round-trip to an external API; everything runs in-process.

## How the pipeline works

Each query runs six steps:

1. **Walk** files in parallel, respecting `.gitignore` and `.vexignore`.
2. **Score** files by keyword overlap with the query — files with zero overlap are skipped.
3. **Chunk** the top files: tree-sitter for supported languages (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#), paragraph/sliding-window for prose.
4. **BM25 pre-filter** narrows to the top ~50 candidates lexically.
5. **Embed** query + candidates via ONNX Runtime on CPU (or NPU on supported hardware).
6. **Rank** by cosine similarity, return top-k.

Steps 2–4 eliminate >99% of chunks before the model runs. A 19,366-file monorepo returns cold in 729ms on a Snapdragon X Elite.

## GitHub issues in the same search

`vex sync github` pulls issues and PRs down as local Markdown files, one file per item, with YAML frontmatter. After that, every `vex` query includes them alongside code. Credentials are only needed during sync; search runs locally.

```bash
vex sync github                            # auto-detect repo from git remote
vex "why did we change the auth flow"      # returns code + issue + PR discussion together
```

Subsequent syncs are incremental — only items updated since the last run are fetched.

## Claude Code skill

`vex` ships with a `/vex` slash command for Claude Code, installed from `.claude/skills/vex/SKILL.md`. The skill teaches Claude to expand queries with synonym hints (`--literal`), run follow-up queries from different angles, and trace code flow from results. One `vex` call replaces 10–15 grep/glob/read calls.
