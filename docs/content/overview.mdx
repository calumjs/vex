`vex` is a Rust CLI that ranks code chunks and GitHub issues by cosine similarity to a plain-English query. No pre-index. No daemon. Query time: 468ms on 585 files, 729ms on 19,366 files, cold.

## The problem

Keyword search fails the vocabulary gap. `rg "retry"` misses `fetch_with_backoff`. `rg "authentication"` misses the PR titled "Session management refactor." The pattern is consistent: the implementation uses different words than the question.

As codebases grow and engineering context spreads across issues, PRs, and design docs, the gap widens. Decisions get repeated. Bugs get reintroduced. Tribal knowledge stays tribal.

`vex` treats queries and code as vectors in the same embedding space and ranks by distance. The words don't have to match.

## The pipeline

Each invocation runs five stages:

1. **Walk** files in parallel, respecting `.gitignore` and `.vexignore`.
2. **Score** by keyword overlap — files with zero match are dropped before the model runs.
3. **Chunk** remaining files with tree-sitter (Rust, Python, JS, TS, Go, C, C++, Java, C#) or paragraph splitting for prose and Markdown.
4. **BM25 pre-filter** narrows to the top ~50 candidates.
5. **Embed** query and candidates with [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) (384-dim, INT8 quantized) via ONNX Runtime. Rank by cosine similarity, return top-k.

Steps 2–4 eliminate >99% of chunks before the model touches them. That's why no pre-index is needed.

vex "error handling with retries" src/

### GitHub issues in the same search

`vex sync github` pulls issues and PRs down as local Markdown under `~/.local/share/vex/sources/github/owner/repo/`. After sync, every query searches them alongside code. Search for "why did we change the auth flow" and get the PR discussion, the architecture doc, and the implementation — ranked together.

### Vocabulary bridging with `--literal`

When the concept is abstract but the implementation detail is specific, `--literal` boosts files that contain a keyword:

```
vex "code that prevents race conditions" --literal lock --literal mutex
```

## Getting started

Requires Rust. The embedding model (~23 MB quantized) downloads automatically on first run.

```bash
cargo install --git https://github.com/calumjs/vex
```

[Full install instructions and flags are in the README](https://github.com/calumjs/vex#install).

An optional Claude Code skill ships in `.claude/skills/vex/`. Copy `SKILL.md` to `~/.claude/skills/vex/` to make `/vex` available globally. The skill guides Claude through synonym-expanded queries and multi-angle follow-ups — replacing 10–15 grep/read calls per investigation with a single vex invocation.
