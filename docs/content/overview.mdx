## The problem it solves

Keyword search assumes you already know what the code calls the thing you're looking for. On any real codebase, you often don't. `rg "retry"` misses `fetch_with_retry`. `rg "authentication"` misses the PR discussion titled "Resilience strategy for upstream timeouts." The concept exists in the code and in the issue tracker — the vocabulary is different.

This gap compounds in AI-assisted workflows. Agents navigating large codebases need context from code *and* the discussions that produced it. If search can't bridge the vocabulary gap, that context stays invisible, decisions get repeated, and bugs get reintroduced.

## How it works

Each query runs a short pipeline:

1. Walk files respecting `.gitignore` and `.vexignore`.
2. Score files by keyword overlap with the query. Files with zero overlap are dropped early.
3. Chunk the top files — tree-sitter for supported languages (Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, C#), paragraph/sliding-window for prose.
4. BM25 pre-filter narrows the pool to the top candidates lexically.
5. Embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized) via ONNX Runtime.
6. Rank by cosine similarity; return top-k.

Steps 2–4 discard >99% of chunks before the neural model runs — that's what makes query-time embedding viable without a pre-built index. On a 19,366-file monorepo, cold search completes in 729ms on a Snapdragon X Elite.

## GitHub sync

`vex sync github` pulls issues and PRs down as local Markdown once; every subsequent `vex` search includes them alongside your code.

```bash
vex sync github                              # auto-detects repo from git remote
vex "why did we change the auth flow"        # returns the PR discussion, the ADR, and the implementation — together
```

Credentials resolve via `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN`. Syncs are incremental; subsequent runs fetch only items updated since the last watermark stored in `.meta/sync-state.json`.

## Getting started

Requires [Rust](https://rustup.rs/). See the [README](https://github.com/calumjs/vex#install) for PATH setup and the optional Claude Code skill (`/vex` slash command — synonym expansion, follow-up queries, flow tracing; replaces 10–15 grep/glob/read calls per agent query).

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB quantized) downloads automatically on first run.
