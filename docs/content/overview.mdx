`vex` is a Rust CLI for semantic code search — `cargo install --git https://github.com/calumjs/vex`, no server, no index, sub-second cold queries.

```
vex "error handling with retries" src/
```

The query and every candidate chunk are embedded at query time using `all-MiniLM-L6-v2` (384-dim, INT8, ONNX Runtime). A BM25 pre-filter eliminates >99% of chunks before the neural model runs, which is what makes indexless embedding viable: a 19,366-file monorepo returns in 729ms on a Snapdragon X Elite.

## Pipeline

Six stages, each discarding work before the next:

1. **Walk** — parallel traversal, respects `.gitignore` and `.vexignore`.
2. **Score** — files with zero keyword overlap are dropped.
3. **Chunk** — tree-sitter boundaries for Rust, Python, JS/TS, Go, C/C++, Java, C#; paragraph/sliding-window for prose. Top 200 files chunked.
4. **BM25 pre-filter** — narrows to ~50 lexical candidates.
5. **Embed** — `all-MiniLM-L6-v2` via ONNX Runtime on CPU; INT8 quantized.
6. **Rank** — cosine similarity, return top-k.

The gap between steps 4 and 5 is the core optimization. By the time the neural model runs, it sees a few dozen chunks, not thousands.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/owner/repo/`. Subsequent syncs are incremental (watermark in `.meta/sync-state.json`). After sync, every `vex` query includes issues and PRs automatically — no separate invocation.

```bash
vex "why did we change the auth flow"
```

Returns the implementation, the PR discussion, and the architecture doc together, ranked by relevance.

## Useful flags

`-k N` (result count), `-g "*.cs"` (glob filter), `--literal mutex` (keyword boost for vocabulary bridging), `-t 0.3` (similarity floor), `--json` (machine output), `--fast` (binary quantization on large trees), `--device npu` (Snapdragon Hexagon NPU path).

## Claude Code skill

`/vex` is a Claude Code slash command in `.claude/skills/vex/`. It teaches agents synonym expansion, follow-up queries, and flow tracing. One `vex` call typically replaces 10–15 grep/glob/read operations from an agent.

## Install

```bash
cargo install --git https://github.com/calumjs/vex
```

The embedding model (~23 MB) downloads automatically on first run. See the [README](https://github.com/calumjs/vex#install) for PATH setup.
