`vex` is a Rust CLI that searches code and GitHub context by meaning, not keyword. No index, no server — a single binary that returns cold in under a second.

```
vex "error handling with retries" src/
```

## The problem

Keyword search assumes you know the vocabulary the code uses. You rarely do. `rg "retry"` misses `fetch_with_retry` and `handle_failure`. `rg "authentication"` misses the PR titled "Resilience strategy for upstream timeouts." The context exists; the words are different; `grep` can't bridge the gap.

This compounds in AI-assisted workflows. If an agent can't find the context, it can't use it — decisions get repeated, bugs get reintroduced, and tribal knowledge stays tribal.

## How it works

Each query runs a short pipeline: walk files (respecting `.gitignore` and `.vexignore`), score files by keyword overlap, chunk the top files (tree-sitter for Rust / Python / JS / TS / Go / C / C++ / Java / C#; paragraph windows for prose), BM25 pre-filter, embed query and candidates with `all-MiniLM-L6-v2` (384-dim, INT8 quantized, ONNX Runtime), rank by cosine similarity.

Steps 2–4 eliminate >99% of chunks before the neural model runs. That is what keeps cold queries under one second: a 19,366-file monorepo returns in 729ms on a Snapdragon X Elite with no pre-built index.

Key flags: `-k N` for result count, `-g "*.cs"` for glob filtering, `--literal <term>` to pin a keyword boost, `-t 0.3` for a similarity floor, `--json` for machine output, `--fast` for binary quantization on very large trees.

## GitHub sync

`vex sync github` materializes issues and PRs as Markdown under `~/.local/share/vex/sources/github/{owner}/{repo}/`. Every subsequent `vex` call searches them alongside code automatically — query "why did we change the auth flow" and get the PR discussion, the architecture doc, and the implementation ranked together.

Sync is incremental (watermark in `.meta/sync-state.json`; `--force` resets it). Credentials resolve via `gh auth token`, `GITHUB_TOKEN`, or `GH_TOKEN` — only needed during sync, not search.

## Claude Code skill

vex ships a `/vex` slash command (`skills/vex/SKILL.md`) that teaches Claude synonym expansion, follow-up queries, and flow tracing. One `vex` call replaces 10–15 grep / glob / read calls from an agent.

## Getting started

`cargo install --git https://github.com/calumjs/vex` builds and installs the binary. The embedding model (~23 MB quantized) downloads on first run. [See the README](https://github.com/calumjs/vex#install) for PATH setup, skill installation, and the full option reference.
